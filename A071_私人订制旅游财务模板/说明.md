# A071 · 私人订制旅游财务模板

> **你说的：** 需要设置一套私人订制旅游的财务模板，包含：客户名字、预订日期、定金金额、出行日期、订单总金额、预计利润、实际利润、尾款收否、销售名字、订单提成；
> 月回款金额、月预订金额、月支出金额、月工资、销售提成、每个订单详细清单、全部预计订单未出行预估总利润。

---

## 一句话

**一本表 `A071_私人订制旅游财务模板.xlsx`。平时只录两张蓝色的表，其余全是自动的；哪里都可以插行、删行、排序。**

记住一条：**接单时在【订单登记】填一行（收了定金就填定金）；之后这一单的每一笔钱——尾款、分期、退款、地接机票酒店等成本——都在【收支登记】记一行、选订单号。**

| 平时录（蓝） | 干什么 |
|---|---|
| **订单登记** | 一单一行：订单号、客户名字、预订日期、出行日期、销售名字、订单总金额、预计成本、定金金额（必填的放最前面），后面是电话、线路、人数、备注，再后面几列可不填：定金收款日期、定金收款账户、取消日期、结算日期、提成比例。右边自动出：**预计利润、实际利润、尾款收否、订单提成**、已收、还没收、实际成本、出行状态 |
| **收支登记** | 定金以外的每一笔钱：收尾款/分期款、退客户款、订单成本（选订单号）；工资、销售提成（选人员）；房租、推广等日常开销；内部转账、股东投入取出 |

自动的（绿）：

| 表 | 是什么 |
|---|---|
| **订单清单** | 「每个订单详细清单」：前 12 列就是你要的那几项（订单号、客户名字、预订日期、定金金额、出行日期、订单总金额、预计利润、实际利润、尾款收否、销售名字、订单提成），可以按预订/出行日期、起止、销售、状态（未出行/已出行/已结算/已取消/没收齐）、客户筛选 |
| **订单详情** | 选一个订单号：订单信息、每一笔收款、每一笔成本、预计和实际利润、提成；A4 竖向直接打印当结算单 |
| **未出行订单** | 顶上大字「**全部预计订单未出行预估总利润**」；① 未出行的单按出行日期排（快出发还没收齐的标红）；② 已出行还没结算/没收齐的；③ 欠供应商、应退客户 |
| **月度汇总** | 选年份：1～12 月的**月预订金额、月回款金额、月支出金额、月工资、销售提成**（已发、应发），还有结算利润、经营利润（估） |
| **工资提成** | 选年、月：每个人的工资、应发提成、已发提成、累计没发的；选一个人看他每单的提成 |
| **资金流水** | 对公账户、微信、支付宝、现金的日记账：期初、收入、支出、期末，逐笔带余额 |

基础（灰）：**基础资料**（公司名称、建账日期、提醒天数；账户和期初余额；收支类别；人员和提成比例）。
另外【首页】有截止日期、本月/本年关键数、未出行预估总利润、该跟进的、各账户余额、提醒、入口、「常见情况怎么记」；【数据校验】列出录错的行和该跟进的事。

## 常见情况怎么记

| 情况 | 记在哪 | 怎么记 |
|---|---|---|
| 接单、收定金 | 订单登记 | 一行：订单号、客户、预订日期、出行日期、销售、订单总金额、预计成本、定金金额（定金不是当天收的，填定金收款日期） |
| 收尾款、分期款 | 收支登记 | 类别「收尾款/分期款」，选订单号，填收入和账户（一次收齐、分几次收都这么记） |
| 付地接、机票、酒店…… | 收支登记 | 选对应类别，选订单号，填支出。开票税费、收款手续费、渠道返佣也这么记（都算这单的成本） |
| 成本先欠着（地接回来再结） | 收支登记 | 照记一行，付款情况选「未付」：算进这单成本，不算钱出去。付了以后清掉「未付」、日期改成付款那天；只付了一部分：原行改成还欠的数，另起一行记付了的 |
| 客户加项目、减项目、部分退团、给折让 | 订单登记 | 直接改「订单总金额」，备注写原价和原因；多收的钱记「收尾款/分期款」，退的钱记「退客户款」 |
| 客户取消 | 订单登记 ＋ 收支登记 | 填取消日期；退给客户的钱记「退客户款」（答应退还没退的选「未付」）；扣损给地接的记订单成本 |
| 结团、成本对完账、尾款收齐 | 订单登记 | 填结算日期：实际利润、订单提成就定下来了，提成算在结算那个月 |
| 发工资、发提成 | 收支登记 | 类别「工资」或「销售提成」，往来对象选人员；一起转的也拆成两行 |
| 房租、推广、办公 | 收支登记 | 选对应类别，不用选订单号 |
| 供应商返佣 | 收支登记 | 按单返的：「供应商返佣（按单）」选订单号、填收入（冲这单成本）；季度返的：「供应商返佣（季度）」，算其他收入 |
| 微信提现到对公、现金存银行 | 收支登记 | 记两行「内部转账」：转出账户那行填支出，转入账户那行填收入 |
| 老板投钱拿钱、借款还款 | 收支登记 | 「股东投入」「股东取出」「借款」「还借款」：进出资金，不算收入支出 |

## 几个数怎么算的

- **预计利润**＝订单总金额－预计成本。**实际利润**＝订单总金额－这单记的全部成本（含还没付的）。
  出行前不显示实际利润；出行了还没结算的是「暂算」（灰字），填了结算日期才定下来。
- **尾款收否**：已收齐 / 未收（只收了定金）/ 部分 / 多收（要看一下）/ 已取消。已收＝定金＋收支登记里这单的收款－退款。
- **订单提成**＝提成比例×利润（结算了按实际利润，没结算先按预计利润估，灰字）；人员可以设成按订单金额提。取消的单没有提成。
- **全部预计订单未出行预估总利润**＝还没出行（没取消）的订单的预计利润合计；没填预计成本的单不算在里面，旁边会写有几单。
- **月预订金额**＝预订日期在这个月的订单总金额。**月回款金额**＝这个月收到的定金＋尾款/分期－退给客户的。
  **月支出金额**＝这个月付出去的订单成本＋工资＋发的提成＋房租等日常费用＋其他支出（还没付的、内部转账、老板拿钱不算）。
- **销售提成**分两个：应发（这个月结算的单的提成）、已发（这个月实际发出去的）；工资提成表里还有累计没发的。
- **经营利润（估）**＝这个月结算的单的实际利润＋取消单留下的钱＋其他收入－工资－应发提成－日常费用－其他支出。
- 已出行、未出行、已收、资金余额都按【首页】的**截止日期**算：空着＝最后一笔的日期。想按今天算，在黄格输入 `=TODAY()`。
- 资金余额只算建账日期以后的钱（建账以前收的定金、付的钱已经在账户期初余额里了；订单里照样算已收、算成本）。

## 插行删行

- 两张登记表、基础资料**哪里都可以插行、删行、排序（整行一起动）**，各表都不会出错（我在 LibreOffice 里试过：中间插一单、插两笔收支、删掉、删原有的再插回、整片按日期倒序排、基础资料一块的空行全删光、整片删光再录）。
- 插进来的行，最右边几列自动列可能是空的（从上一行往下拉一下就有），不影响任何汇总。
- 绿色的表和首页是自动的，有保护（没有密码），只有黄格子能改。
- 改了销售名字、收支类别名，用「查找替换」把两张登记表里的旧名字也改掉。
- 容量：订单 3000 单、收支 8000 笔、账户 20 个、收支类别 80 个、人员 50 个。不用一年一本（订单常常跨年出行），用满了另起一本；超了【数据校验】和首页都会提醒。

## 技术说明

- 只用 Excel 2010 / WPS 都有的函数，没有数组公式、没有 INDIRECT/TODAY；下拉列表用了 OFFSET（只在下拉里用）。
- 生成脚本在 `生成脚本/`：`python3 build.py`（预置清单和示例行在 `data.py`；口径见 `设计.md`）。
