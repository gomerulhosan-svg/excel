# A071 私人订制旅游财务模板 · 设计

## 用户要的（原话）

客户名字 预订日期 定金金额 出行日期 订单总金额 预计利润 实际利润 尾款收否 销售名字 订单提成；
月回款金额 月预订金额 月支出金额 月工资 销售提成 每个订单详细清单 全部预计订单未出行预估总利润。

## 总思路

一本表。平时只录两张蓝表，其余全自动；录入表随便插行、删行、排序不出错（跟 A070 一样的做法）。
**只有一条记账规则**：接单时在【订单登记】填一行（收了定金填定金）；之后这一单的每一笔钱（尾款、分期、退款、成本、税费、手续费）都在【收支登记】记一行、选订单号。
客户加项目、减项目、部分退团、给折让：直接改订单总金额（备注写原价和原因）。

| 表 | 组 | 干什么 |
|---|---|---|
| 首页 | 首页 | 截止日期（黄格，空＝最后一笔的日期）；本月/本年：月预订金额、月回款金额、月支出金额、月工资、销售提成（已发/应发）、结算利润、经营利润（估）；全部预计订单未出行预估总利润；该跟进的；各账户余额；提醒；入口；常见情况怎么记 |
| **订单登记** | 录入（蓝） | 必填：订单号、客户名字、预订日期、出行日期、销售名字、订单总金额、预计成本、定金金额；常用：电话、线路、人数、备注；可不填：定金收款日期（空＝预订日期）、定金收款账户（空＝默认）、取消日期、结算日期、提成比例（空＝按人员）。右边自动：预计利润、实际利润、尾款收否、订单提成、已收、还没收、实际成本、出行状态、这一行的问题 |
| **收支登记** | 录入（蓝） | 日期、收支类别、订单号（订单的钱要选；下拉只列没结算的单）、往来对象（人员下拉，供应商手打）、摘要、收入、支出、账户、付款情况（空＝已付/未付）、备注。右边自动：归类、订单客户、这一行的问题 |
| 订单清单 | 查看（绿） | 每个订单详细清单：按预订/出行日期、起止、销售、状态、客户筛选；前 12 列按用户原话的顺序 |
| 订单详情 | 查看 | 选一个订单：信息、收款明细、成本明细、利润、提成；A4 竖向当结算单打印 |
| 未出行订单 | 查看 | 全部预计订单未出行预估总利润；① 未出行（按出行日期，快出发没收齐标红）；② 已出行没结算/没收齐；③ 欠人家的（欠供应商、应退客户、其他未付） |
| 月度汇总 | 查看 | 选年份：1～12 月 × 预订、回款、支出、其他、结算、经营利润（估）、出行 |
| 工资提成 | 查看 | 选年、月、人员：每人工资、应发提成、已发提成、累计未发、预估提成；所选人员的订单提成明细和收到的钱 |
| 资金流水 | 查看 | 选起止、账户、类别：各账户期初/收入/支出/期末；定金和收支登记的钱合在一起按日期排、带余额 |
| 基础资料 | 基础（灰） | ① 公司名称、建账日期、出发前几天提醒收尾款（15）、出行后几天提醒结算（30）；② 账户（期初余额）；③ 收支类别（方向、归类）；④ 人员（岗位、提成基数、提成比例） |
| 数据校验 | 校验 | 两张登记表逐行 ✗/⚠、基础资料重名、对数检查和该跟进的、容量；最后列出有问题的行 |
| 隐藏 | — | `_参`、`_表`（基础资料镜像＋下拉清单）、`_单`（订单逐行算）、`_收`（收支逐行算）、`_序`（资金流水排序键） |

## 口径

**截止日期**：首页黄格；空＝最后一笔＝MAX（预订日期、定金收款日期、取消日期、结算日期、收支登记已付行的日期）——不取出行日期、不取未付行，所以不会被将来的日子推着走。
不用 TODAY（易失函数会让每次编辑都整本重算）；想按今天算，用户自己在黄格输入 =TODAY()。黄格早于最后一笔时首页红字提醒。

**订单**

- 订单号：用户编，不能重复；整列文本格式；公式里比较用键＝`"#"&订单号`（过 esc）。收支登记下拉选「号｜客户｜出行 m/d」取「｜」前面。
- 已收 ＝ 定金（定金收款日期 ≤ 截止）＋ 收支登记这单「订单收款」－「订单退款」（已付、日期 ≤ 截止）。
- 还没收 ＝ 订单总金额 － 已收（已取消＝0）。尾款收否：已取消 / 已收齐 / 未收（只收了定金）/ 部分 / 多收 x（⚠）。
- 实际成本 ＝ 这单「订单成本」类 支出－收入（供应商退回、按单返佣记收入冲成本），**含未付、不限日期**。
- 预计利润 ＝ 订单总金额 － 预计成本（没填预计成本＝0、⚠、不算进预估总利润；已取消＝实际利润）。
- 实际利润 ＝ 有效金额 － 实际成本；有效金额：正常＝订单总金额，已取消＝已收 － 应退未退（收支登记里未付的「退客户款」）。
  显示：未出行不显示；已出行没结算＝暂算（灰斜体）；已结算、已取消正常显示。
- 出行状态（按截止日）：已取消（取消日期 ≤ 截止；取消日期填错也算）> 已结算（结算日期 ≤ 截止）> 已出行（出行日期 ≤ 截止）> 未出行。
- 订单提成 ＝ 比例 × 基数，负数按 0，已取消＝0；比例：订单填了用订单的，否则用人员的（≥1 当百分数）；基数（人员设）：利润（结算了用实际利润，没结算用预计利润）或订单金额。
  **应发**＝已结算（没取消）的单，算在结算月；没结算的是预估。
- 全部预计订单未出行预估总利润 ＝ 未出行（出行码 0）且填了预计成本的预计利润合计；另显示没填预计成本的单数和金额。

**钱**（资金余额、资金流水、月回款、月支出）：只算日期在 [建账日, 截止日] 之间、已付的。建账以前收付的钱已经含在账户期初余额里（订单里照算已收、成本）。

- 收支登记归类：订单收款、订单退款、订单成本（这三类要选订单号）、工资、销售提成（往来对象要选人员）、日常费用、其他收入、其他支出、内部转账、资金往来（股东投入取出、借还款，不算收支）。
- 付款情况＝未付：不进资金、不进月支出；订单成本未付＝欠供应商（照算进实际成本），订单退款未付＝应退客户，别的＝其他未付。收入选未付 ✗。付了以后清掉「未付」、日期改成付款那天。
- 月预订金额 ＝ 预订日期在这个月的订单总金额（含后来取消的）。当月取消（按取消日期）另列。
- 月回款金额 ＝ 定金 ＋ 收尾款/分期 － 退客户款（按收到/退出的日期）。
- 月支出金额 ＝ 订单成本（已付）＋ 月工资 ＋ 销售提成（已发）＋ 日常费用 ＋ 其他支出。
- 销售提成（应发）＝ 当月结算的单的订单提成；（已发）＝ 收支登记当月发的。
- 经营利润（估）＝ 结算利润 ＋ 取消单留存（按取消日期）＋ 其他收入 － 月工资 － 销售提成（应发）－ 日常费用 － 其他支出。
- 账户余额（截至 d）＝ 账户期初 ＋ 定金（收款账户，定金日期在 [建账日, d]）＋ 收支登记净额（账户，在期，日期 ≤ d）。

## 容量

订单 3000 单、收支 8000 笔、账户 20、收支类别 80、人员 50。不分年度（订单跨年出行），报表按年份选；用满了另起一本。

## 做法（跟 A070 一样）

- 录入表只放录入列＋右边只给人看的显示列；逐行计算放隐藏表 `_单`、`_收`，按「第 n 条」取数：`INDEX(录入表!$X$表头行:$X$1048576, n+1)`。
- `_单`、`_收` 的原始取数列不引用截止日（截止日只从原始数据推出来，不会循环）。
- 查看表只用定义名称做 SUMIFS/COUNTIFS，合计带「有效＝1」；按键做条件外面套 IF(键="",0,…)；清单用隐藏列「排序键＋SMALL」或「计数列＋MATCH」取第 k 条。
- 只用 Excel 2010 / WPS 都有的函数：不用数组公式、INDIRECT、TODAY；OFFSET 只在下拉来源里用。名字做条件过 esc()（~ * ? 转义）。
- 基础资料几块上下排，整行删多了块变短也不会读到下一块（_参 里有每块能放到第几个）。
