### 1.3 各分包明细表的格式
两种版式：

| 版式 | 用的表 | 列（第 2 行表头，第 3 行起数据） |
|---|---|---|
| 11 列 | 恩旗老叶、吴群、吴聪 | A 日期、B 项目名称、C 应付金额、D 已付金额、E 付款日期、F 付款账户、G 收款账户、H 已开票金额、I 税率、J 税额、K 备注2（**没有开票日期**） |

- 右边是 `=PIVOTBY(TRIMRANGE(B2:B999),,TRIMRANGE(C2:D999),SUM,3)` 透视（按项目汇应付、已付），放在 M1 或 N1；龚文坚那张放在 N14。
- 第 1 行 A1 是标题（如「老叶应付账款明细表」），部分表没有标题。J1/K1 是「返回总表」。
- **一行同时有应付和付款，但两者没有对应关系**：C 是这一批的结算或送货金额，D 是某一次付款。同一行的 E（付款日期）常常和 A（日期）不同，项目 B 也只对 C 有意义。共安门业、张小朋、龚文坚最明显。

## 7. 给新账套的落地建议（只限本组范围）
- **基本信息**分板块：甲方 / 材料商 / 分包 / 机械运输 / 人工（管理人员、工人、代缴过账人员）。
  - 分包板块有「承包方式」「开票主体」「默认税率」「收款人别名」几列。
  - 班组工人放进分包的「收款人」名单，不要再当成往来单位类型「分包」。
- **应付**：一行一批（日期、供应商、项目、内容、应付、税率）。付款只在流水记，流水里有「供应商」列（下拉），冲应付。
  - 收票单独登记，或者在应付行上加「已开票金额 / 开票日期 / 税率」。
  - 总表按供应商显示：应付、已付、未付、已开票（分税率）、未开票，可以选时间段，也可以只看一家带出明细（用户第 09、14 条）。
  - 每家的明细版式照用户的分包分表：日期 / 项目 / 应付 / 已付 / 付款日期 / 付款账户 / 收款账户 / 已开票 / 开票日期 / 税率 / 税额 / 备注。
- **机械**：同上。另外可以保留「机械台班明细」（日期、项目、班组、种类、单价、时段、小时、金额），按月汇总进应付。
- **考勤**：8 对项目，月份存日期。「同一项目填两次」和「超过当月天数」仍然只提示。年后、年前的天数要分开月份录。
- **工资汇总、用工成本表**：起止日期可以随便选，项目可以多选（或者先选再筛）。
- **未发清工资**：做成「历史欠薪/补发」台账（§3.3）。
- **所有引用往来单位的辅助表**，都不能写成「固定指向某一行」，用户插行、删行都不能出 #REF!（§4.6 的根子）。
