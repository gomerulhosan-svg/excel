# A066 第二版 · 报表口径（写查看表/报表的人必须照这个取数）

> 契约：`layout.py`（表名、列、定义名称、_汇 布局、公式小函数）、`设计.md`（总原则）。
> 隐藏表：`_收`（收支登记逐条）、`_应`、`_付`、`_考`、`_票`、`_表`（基本信息镜像）、`_参数`、`_汇`（s_sum.py）。
> **报表只用定义名称**（收_xxx、应_xxx、付_xxx、考_xxx、票_xxx、项目_xxx、供应商_xxx、人员_xxx、账户_xxx、标准_xxx、期初_xxx、P_xxx、汇_xxx），
> 不直接引用录入表的格子（唯一例外：报表自己的选择格）。

## 0. 公式约束（make.check_formulas 会拦）

- 不用 XLOOKUP/FILTER/UNIQUE/SORT/LET/IFS/MAXIFS/MINIFS/SWITCH/TEXTJOIN/CONCAT/INDIRECT/OFFSET/TODAY/NOW/AGGREGATE。
- **不要数组写法**：`MAX(INDEX(条件*区域,0))`、`SUMPRODUCT(MAX(...))` 在 LibreOffice/WPS 不一定按数组算。一律用 SUMIFS/COUNTIFS；
  取「最后一笔日期」之类用「排号」法（COUNTIFS 数出第几、再 SUMIFS/MATCH 取），或者 SMALL/LARGE 作用在一个**普通区域**上（不是表达式）。
  SUMPRODUCT 只用于「区域×区域」的纯乘加，里面不套 MAX/MIN/LEN/ROW/ABS/IF。
- 名字当 SUMIFS/COUNTIFS 条件时用 `esc(格)` 转义（名字里可能有 * ? ~）。MATCH 精确匹配不用转义。
- 日期条件：`收_日期,">="&起,收_日期,"<="&止`。无效行的日期＝0、金额＝0（_收 的 收入/支出/净额/已开票 只在有效时有值），所以不用再判有效。
- 一格公式不超过 8000 字符，括号配好；每个可能出错的查找包 IFERROR。

## 1. 期间

- 首页：报表年度 `P_年度`、截止日期 `P_截止`（空＝最后一笔流水日）、`P_年初`＝年度 1 月 1 日。
- **每张查看/项目/报表有自己的起止黄格**（FILL_SEL 亮黄，保护时不锁）。空着＝默认：起＝`P_年初`、止＝`P_截止`。
  在黄格旁边（或下面）放「有效起止」显示格：`=IF(ISNUMBER(黄格),INT(黄格),默认)`，后面公式都引用有效格。
- 利润表、资产负债表的黄格位置是**固定的**（_汇 要读）：利润表本期起 `利润表!C3`、止 `利润表!E3`；资产负债表日期 `资产负债表!C3`。
  有效日期用名称 `汇_利润起`、`汇_利润止`、`汇_负债日`。

## 2. 收支（_收）

| 东西 | 取法 |
|---|---|
| 一个账户在 d 日的余额 | `INDEX(账户_期初,k)` ＋ SUMIFS(收_净额,收_账户,名,收_日期,"<="&d) − SUMIFS(收_净额,收_对方账户,名,收_归类,"内部转账",收_日期,"<="&d) |
| 账户本期收入（含转入） | SUMIFS(收_收入,收_账户,名,日期段) ＋ SUMIFS(收_支出,收_对方账户,名,收_归类,"内部转账",日期段)（对方账户那边：本行支出＝它收到） − 对方账户那边本行收入 …… **简单写法**：本期净额＝余额(止)−余额(起−1)；收入列＝SUMIFS(收_收入,账户)＋SUMIFS(收_支出,对方账户,内部转账)；支出列＝SUMIFS(收_支出,账户)＋SUMIFS(收_收入,对方账户,内部转账)；期末＝期初＋收入−支出 |
| 货币资金 | 账户类型 银行/现金/专户。**个人户**（老板微信等）不算货币资金，按人进「个人往来」。专户余额应为 0（不为 0 要提示） |
| 归类 | `收_归类`（21 个固定代码，见 layout.CATS）；空＝没认出来（未分类） |
| 成本费用行 | `收_成本类`≠"" 的行：材料/分包/机械/人工/其他直接费/管理费用/财务费用/营业外支出/未分类；金额＝`-收_净额` |
| 费用归属 | `收_归属`：项目成本（一定有工程项目 `收_项目`）/ 待摊费用 / 公司费用（财务费用、营业外、未分类一律公司费用） |
| 冲应付 | `收_冲应付`=1：材料/分包/机械付款，供应商在应付登记里有行 → 不是成本，冲应付（付款额＝`-收_净额`） |
| 冲工资 | `收_冲工资`=1：工资发放给有考勤的人（考勤起算月以后、人工口径＝考勤应发）→ 冲应付工资 |
| 过账 | `收_过账`=1：过账人员（姚俊强）的工资/代付 → 其他应收·代收代付，不进成本 |
| 往来对象 | `收_人员`（个人借款的人、备用金、报销、垫付）、`收_供应商`、`收_客户` |

## 3. 收入、应收（_应 ＋ _收 工程款收款）

- 合同口径（应收账款表、应收对账）：
  - 应收总额＝合同金额（`项目_合同`）＋ SUMIFS(应_应收额, 项目, 日期≤止)（补充协议、签证、结算调整为正，扣款为负）＋ 期初应收（期初_类型="应收账款"，期初_项目）。
  - 已收＝SUMIFS(收_净额, 收_归类,"工程款收款", 收_项目, 日期段)（含专户、个人户收到的工程款）。
  - 已开票＝SUMIFS(应_开票额, 应_项目, …)；销项税 `应_销项税`；税率 `应_税率`（同一项目可能多个税率：按 9%/13%/6%/3%/1% 分列，或显示「最近一张发票的税率」）。
  - 未收＝应收总额−已收；未开票＝应收总额−已开票；开票未收＝已开票−已收。
  - 保证金 `项目_保证金`，质保金 `项目_质保金额`（空＝比例×应收总额），质保到期 `项目_质保到期`。
- 会计口径（利润表、资产负债表、项目利润表）：**确认收入**按 `P_收入口径`，逐项目、按累计数算：
  `rev_formula(累计开票, 累计收款, 累计产值)`（layout 里的函数；默认「开票与收款取大」：有确认产值用产值，否则 MAX(开票,收款)）。
  期间收入＝累计(止) − 累计(起−1)。累计用 `cum_kp(项目,日)`、`cum_sk(项目,日)`、`cum_cz(项目,日)`。
  公司合计已经在 _汇 算好：`汇_收入年初前`、`汇_收入1月`…`汇_收入12月`、`汇_收入利润起前`、`汇_收入利润止`、`汇_收入负债日`（都是累计数）。
- 应收余额（会计）＝期初应收＋累计确认收入−累计收款，按项目分正负：`汇_应收负债日`、`汇_预收负债日`（年初前同理）。

## 4. 应付（_付 ＋ 冲应付的付款）

- 应付＝SUMIFS(付_应付额, 供应商/项目/类型, 日期)；已开票＝`付_已开票`（按 `付_开票日期`）；进项税 `付_进项税`（专票）；税率 `付_税率`；发票类型 `付_发票类型`。
- 已付＝−SUMIFS(收_净额, 收_供应商, 名, 收_冲应付, 1, 日期)（含专户、个人户付的）。**另外**供应商在应付登记里没有行时，付给他的钱是直接成本
  （`收_冲应付`=0、`收_成本类`=材料/分包/机械），应付对账里可以单列「直接付款（没登记应付）」。
- 未付＝期初应付＋应付−已付；未开票＝应付−已开票。
- 分包包工包料：同一家可以在应付登记分两行（材料 13% 专票、人工 1% 普票），税率分列汇总。
- 期初应付：期初_类型="应付账款"，期初_对象＝供应商。
- 资产负债表：`汇_应付负债日`、`汇_预付负债日`。

## 5. 工资（_考 ＋ 工资发放）

- 应发（考勤）：`考_应发`（不含过账人员）；按项目＝8 对 `考_项目i`/`考_金额i`（金额只给工程项目）；`考_未分摊`＝管理人员/公司（办公室）部分。
- 进成本、进应付工资的只是 `考_计提`=1 的行（考勤起算月以后、人工口径＝考勤应发、不是过账）。工资表、工资汇总、用工成本表**显示**用不带计提的数（考勤录了就显示）。
- 已发＝−SUMIFS(收_净额, 收_归类,"工资发放", 收_人员, 名, 日期)（含专户代发、工资退回为负）。过账人员单独看（`收_过账`）。
- 欠薪（某人到 d）＝期初欠薪（`人员_期初欠薪`＋期初_类型="应付工资"）＋应发(≤d，月份≥起算) − 已发(≤d，日期≥起算)。
- 应付工资（资产负债表）＝Σ期初欠薪 ＋ SUMIFS(考_应发,考_计提,1,月≤d) − (−SUMIFS(收_净额,收_冲工资,1,日期≤d))。
- 人工成本：项目＝Σi SUMIFS(考_金额i, 考_项目i, 项目, 考_计提,1, 考_月 段) ＋ 现金人工（收_成本类="人工"、收_归属="项目成本"、收_项目）。
  月份条件用 `考_月`（当月 1 号）或 `考_年月`（YYYYMM）。

## 6. 个人往来（按人）

| 块 | 取法（人＝`收_人员`；正负按「钱进公司为正」的净额） |
|---|---|
| 借款 | 借入＝SUMIFS(收_收入,归类"个人借款",人)＋（支出栏负数）：**用净额**：净额>0 的部分＝借入、<0＝归还。写法：借入＝SUMIFS(收_净额,…,收_净额,">0")，归还＝−SUMIFS(收_净额,…,收_净额,"<0")；期初＝期初_类型"个人借款"；余额＝期初＋借入−归还（公司欠他） |
| 垫付报销 | 他名下个人户（`账户_所属人`＝他）里的支出＝垫付；个人户的收入＝他替公司收的钱；公司还他的＝归类"报销还款"、人员＝他；已开票＝个人户支出行的 `收_已开票`；欠票＝垫付里成本费用行（`收_成本类`≠""）的金额−已开票；余额：`_汇` 人员块（正＝他手上有公司的钱，负＝公司欠他） |
| 备用金 | 归类"备用金"：领＝−净额>0 部分，退＝… ；余额＝期初＋领−退 |
| 代收代付（过账） | 归类"代收代付" ＋ 归类"工资发放"且 `收_过账`=1：公司替他付＝−净额>0，退回＝净额>0；未退＝期初＋代付−退回 |
| 往来款 | 归类"往来款"、对象＝`收_往来对象` |

## 7. 管理费分摊（待摊）

- 待摊池（年）＝ `收_归属`="待摊费用" 的成本费用 ＋ `考_未分摊`（计提的）。年度表在 _汇：`汇_年`、`汇_待摊池收`、`汇_待摊池考`、`汇_待摊池`、`汇_基数`、`汇_费率`、`汇_已摊`、`汇_未摊`（8 年，第 i 个＝YEAR0+i−1）。
- 分摊依据 `P_分摊依据`：施工费（人工＋分包＋机械，默认）/ 直接成本。逐条已经算好「基数」「摊费」：
  项目在期间摊到的管理费＝SUMIFS(收_摊费,收_项目,p,日期段)＋SUMIFS(付_摊费,付_项目,p,日期段)＋Σi SUMIFS(考_摊i,考_项目i,p,考_月段)。
  项目在期间的分摊基数同理用 收_基数、付_基数、考_金额i×计提（`考_基数`是整行合计，按项目要用 考_金额i 加 考_计提=1 条件）。
- 费率按年：这一年的待摊池 ÷ 这一年所有项目的基数。完工后没有施工费就不摊。公司费用（财务费用、营业外、罚款）不摊。

## 8. 项目成本（项目 p、期间 [起,止]）

| 成本 | 取法 |
|---|---|
| 材料 | SUMIFS(付_应付额,付_项目,p,付_类型,"材料",付_日期段) ＋ −SUMIFS(收_净额,收_项目,p,收_成本类,"材料",收_归属,"项目成本",收_日期段) |
| 分包、机械 | 同上（类型"分包"/"机械"，成本类"分包"/"机械"） |
| 人工 | 考勤：Σi SUMIFS(考_金额i,考_项目i,p,考_计提,1,考_月段) ＋ 现金：−SUMIFS(收_净额,收_项目,p,收_成本类,"人工",收_归属,"项目成本",…) |
| 其他直接费 | 付_类型"其他" ＋ 现金 收_成本类 "其他直接费" 和 "管理费用"（归属项目成本的） |
| 税金（估算） | 销项税（应_销项税，按开票）− 进项税（付_进项税，专票；小规模不抵）＋ 附加（(销项−进项)×P_附加税率）。小规模：开票额/(1+P_征收率)×P_征收率×(1+附加率) |
| 管理费分摊 | §7 |
| 收入 | §3 会计口径 |
| 毛利＝收入−直接成本−税金；净利＝毛利−分摊管理费 |

- 「开工至今」：起＝`项目_开工有效`（空＝建账日），止＝截止日。期初余额里项目的数（期初_项目）只进「开工至今」。

## 9. 公司利润表（期间 [起,止]，全公司）

- 工程收入＝汇_收入(止) − 汇_收入(起前)。其他收入＝SUMIFS(收_净额,收_归类,"其他收入",…)。未分类收支＝SUMIFS(收_净额,收_成本类,"未分类",…)（可正可负）。
- 营业成本：材料、分包、机械、其他直接费＝应付登记全部（含没项目的）＋现金成本类（归属＝项目成本；管理费用归属项目成本的进其他直接费）；
  人工＝SUMIFS(考_应发,考_计提,1,…) − 考勤未分摊部分 ＋ 现金人工（归属项目成本）。
- 管理费用＝待摊费用全部 ＋ 公司费用里的（成本类 不是 财务费用/营业外支出/未分类）＋ 考勤未分摊（管理人员工资）。
  写法：−SUMIFS(收_净额,收_归属,"待摊费用") − SUMIFS(收_净额,收_归属,"公司费用") − 财务费用 − 营业外支出 − (−未分类的那部分) …… 注意未分类可正可负，单列。
- 财务费用、营业外支出：成本类。
- 税金及附加（估算）：§8 公司口径。
- 净利润＝收入合计−营业成本−管理费用−财务费用−营业外支出−税金±未分类。
- **每一笔成本费用只能进一行**：现金行按 收_成本类×收_归属 分；冲应付/冲工资/过账的行成本类为空，不进利润表。

## 10. 资产负债表（日期 d＝汇_负债日；对比列＝年初前）

| 项目 | 取法 |
|---|---|
| 货币资金 | `汇_货币资金负债日`（银行＋现金＋专户） |
| 应收账款 / 预收账款 | `汇_应收负债日` / `汇_预收负债日` |
| 预付账款 / 应付账款 | `汇_预付负债日` / `汇_应付负债日` |
| 其他应收·个人手上的公司钱 / 其他应付·个人垫付未报销 | `汇_个人持有负债日` / `汇_个人垫付负债日` |
| 其他应收·保证金押金 | 期初(保证金押金) − SUMIFS(收_净额,收_归类,"保证金押金",≤d) |
| 其他应收·备用金 | 期初(备用金) − SUMIFS(…"备用金"…) |
| 其他应收·代收代付 | 期初(代收代付) − SUMIFS(…"代收代付"…) − SUMIFS(收_净额,收_归类,"工资发放",收_过账,1,…) |
| 其他应收·往来（净） | 期初(其他应收) − 期初(其他应付) − SUMIFS(…"往来款"…)（负数放其他应付） |
| 固定资产 | 期初(固定资产) − SUMIFS(…"固定资产购置"…) |
| 应交税费 | 期初(应交税费) ＋ 累计估算税金(≤d) − (−SUMIFS(…"税费"…))（负数＝留抵，放资产） |
| 应付工资 | §5 |
| 其他应付·个人借款 | 期初(个人借款) ＋ SUMIFS(…"个人借款"…) |
| 短期借款 | 期初(短期借款) ＋ SUMIFS(…"银行借款"…) |
| 实收资本 | 期初(实收资本) ＋ SUMIFS(…"股东投入"…) |
| 未分配利润 | 期初未分配（＝期初资产−期初负债−期初实收资本，自动倒挤）＋ 建账以来累计利润(≤d) |

- 「累计利润」用利润表同一套算法，期间＝[很早, d]（收入用 汇_收入负债日，期初应收不算收入）。
- 期初（建账日的数）：账户期初（基本信息②）、期初余额表、人员期初欠薪。期初资产＝账户期初（全部，个人户按人进个人往来）＋期初各资产类；
  期初负债＝期初各负债类＋期初欠薪。
- **资产＝负债＋权益必须相等**（数据校验检查；不等就是哪一类漏了）。

## 11. 清单（明细）的做法

- 报表右边隐藏列放「条件 1/0 ＋ 累计计数」（common.counter），第 k 行用 `kth(k, 计数列, 起行, 行数)` 取第几条，再 `INDEX(收_xxx, 第几条)`。
- 要按日期排序时用 common.skey/ksorted（日期×10000＋序号，SMALL 取）。
- 清单显示的行数有限（比如 300 行）；超出时在表头提示「共 N 条，只显示前 300 条，请缩短日期」。
