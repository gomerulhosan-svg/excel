## 生产这块怎么处理（你最关心的）

**财务不跟生产过程，也不用盘进销存。**
- 料、外协、外购成品**买进来（采购登记）就算成本**；工人工资、电费、厂房租金、设备维修、刀具辅料（资金台帐里「算到哪」是生产成本的类别）也算生产成本。
- 月底**大概估一下**仓库里还有多少料、在制品、成品（包括已经发货还没定价的、放在外协厂的料），按买价估，填在【基础资料】⑤（不填也行）。
  利润表用「上次估的－这次估的」把没用掉的扣回来（库存多了，成本就少算；库存少了，成本就多算）。
- 没估的月份利润只供参考（料可能是这个月买、下个月才用），**看几个月合起来的更准**。以后能盘点了，把估值填准，利润就准了。
- 机床等设备买的时候记「买设备」（不算当月费用），在基础资料填一个每月折旧（估），每月算进成本。
- 销售收入按**发货**算（定了价才有金额），回款只冲客户欠款，不算收入；所以「发了货没回款」也是收入，「回了款」不是收入。

## 常见情况怎么记

| 情况 | 记在哪 | 怎么记 |
|---|---|---|
| 客户打来货款 | 资金台帐 | 类别「收客户货款」，往来单位选客户，填收入。退给客户的钱同一个类别记支出 |
| 收到承兑汇票 | 资金台帐 | 账户选「承兑汇票」、类别「收客户货款」、往来单位选客户、填收入；票号到期日写摘要 |
| 承兑背书付货款 | 资金台帐 | 账户选「承兑汇票」、类别「付供应商货款」、往来单位选供应商、填支出 |
| 承兑贴现、到期托收 | 资金台帐 | 两行「内部转账」：承兑汇票支出票面、银行收入票面；贴息另一行「承兑贴息」 |
| 发货 | 销售登记 | 一个产品一行；没定价先空着，定价后回原行补，日期不改 |
| 钢材、外协、外购成品到货 | 采购登记 | 按送货单、磅单、结算单填金额；月底才定价的先空着 |
| 付供应商货款 | 付款审批 → 资金台帐 | 先申请 → 老板批 → 付款时类别「付供应商货款」、往来单位选供应商、关联单号选审批单 |
| 零星现买（当场付清、不用对账） | 资金台帐 | 类别「零星料钱（现买）」，不用往来单位。**登过采购登记的货付款一定选「付供应商货款」**，不然成本算两遍（表上会提醒） |
| 工资、电费、房租、社保 | 资金台帐 | 选对应类别；上个月的工资电费「所属月份」填几月（填 9 就行）。每月固定的在【固定支出】登一次 |
| 每月计划要付的（电费、税、利息） | 付款审批 | 计划付款日期填哪天，老板批了，资金计划那个月就算进去 |
| 退货、扣款、折让、质量罚款 | 销售/采购登记 | 记一行负数，产品名称写原因 |
| 开发票、收发票 | 发票登记 | 一张一行 |
| 账户之间倒钱 | 资金台帐 | 两行「内部转账」：转出账户支出、转进账户收入；手续费另一行 |
| 老板投钱拿钱、借款还款、保证金、还信用卡 | 资金台帐 | 选「老板存取」「借款」「还借款」「保证金」「还信用卡」：进出资金，不算收入支出（信用卡里花的钱要算费用的，按用途分开记） |
| 买机床 | 资金台帐 | 类别「买设备」 |
| 每天采购计划 | 采购计划 | 提交一行 → 老板审批 → 买了选已下单、已到货；【采购计划汇总】打印当天的单 |

## 几个数怎么算的

- **截止日期**（首页黄格）：空着＝最后一笔的日期（资金台帐、销售、采购里最晚的）。余额、欠款都算到这一天，「今天」「本月」就是这一天、这个月。
  最后几笔要是比别的晚一个多月（多半年份打错了），截止日期不跟过去，首页和数据校验会提醒。想按今天算，黄格里输入 `=TODAY()`。
- **即时余额**（资金台帐右边）按表里**上下顺序**算，跟手写帐一样；某一行日期比上面同一账户的早会提醒，整表按日期排一下序就对了。
  各报表里的余额都按**日期**算，不受录入顺序影响。
- **可用资金**＝7 个银行/微信账户合计，不含承兑汇票（承兑单列「手上承兑汇票」）。
- **客户欠款**＝期初应收＋发货－回款；**欠供应商**＝期初应付＋到货－付款。负数显示「预收」「预付」。
- **未开票**＝期初未开票＋要开票的发货－已开出的发票；**欠票**同理。期初未开票、期初欠票不知道就不填（从建账日起跟票）。
- **付款审批**：已付＝资金台帐里关联单号是这张单的付款；状态：待审批、待付款、部分已付、已付、不同意、暂缓。
- **固定支出已付**：资金台帐关联单号选了编号的；没选的，收支类别（填了收款单位的再加往来单位）对得上也算。带审批单号的付款不算固定支出，不会重复扣。
- **利润**＝销售收入－（采购＋生产成本＋折旧＋库存变动）－销售/管理/财务费用－税金＋其他收入－其他支出。金额都按实际成交价（带票的是含税价），跟对账一致。

## 插行删行

- 所有登记表、往来单位、固定支出、基础资料**哪里都可以插行、删行、排序（整行一起动）**，各表不会出错。
- 插进来的行，最右边几列自动列可能是空的（选上一行右边灰色几格往下拉一下就有），不影响任何汇总；数据校验会数出有几行。
- 登记表打印时只打到最后一行有内容的地方。绿、紫、橙色的表和首页是自动的，有保护（没有密码），只有黄格子能改。
- 改了客户、类别、账户的名字，用「查找替换」把登记表里的旧名字也改掉（往来单位的全称、其他叫法登记上，写哪个都认）。
- 容量：资金台帐 6000 笔、销售/采购各 3000 行、发票/付款审批/采购计划各 2000 行、往来单位 300 家；用满了另起一本（期初余额、期初欠款填上一本的数）。
