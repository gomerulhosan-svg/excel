# A065 · 财税代理多公司收支模板

> 你的要求：
> 1. 客户和供应商可以绑定收支项目；客户来款第一次是「新增」，第二次起是「续费」，要改成咨询服务之类的可以手工调整；
> 2. 根据电子税务局导出的购销发票做应收应付；
> 3. 社保挂靠和费用类的需要手工筛选；
> 4. 银行、微信、支付宝等流水导出后，绑定过客户、供应商名称的自动匹配，减少手工筛选，在基础资料里设置；
> 5. 5 家公司，银行、微信、支付宝等账号 15 个。银行流水和购销发票要分出公司；有内部公司之间的划转；要知道应收应付；
>    其他应收应付就是借款之类的；要统计费用；要一张业务用的简易现金流量表，不要税务那种。模板要能跨年度用；
> 6. 已经导出的这份银行流水要能自动提取到资金台帐，并且根据流水自动填好供应商、客户列。资金台帐用混合录入，
>    每笔算出即时余额，后面有供应商、客户、费用、所属公司等列，用来关联各张报表。
>
> 另外附了：销项发票、进项发票（电子税务局导出）、农行流水（9 月），以及一张「收支类型」截图。

## 三、每月怎么做

### 1. 导银行流水（农行）

1. 网银导出明细，打开，选中明细行的「交易时间～摘要」8 列（农行就是 A～H 列，不要表头），复制；
2. 到【资金台帐】C 列最下面的空行粘贴；
3. 在 B 列把这几行的**账户**选上（选一格往下拖）；
4. 看 X 列「校验」：√ 就好了；**✗ 的点 X 列筛选，在 K 列选往来单位或 L 列选收支项目**；
   常来往又认不出的，到【往来单位】登记一下（能绑项目的绑上），以后就自动认了。
   【数据校验】下面会列出流水里还没登记的户名，复制过去就行。

### 2. 微信、支付宝、其他银行

【流水格式转换】：B3 选格式（农行网银 / 微信账单 / 支付宝账单 / 单列金额 / 自定义），E3 选账户，
导出文件的明细整块粘到 A15，右边 S～AA 就排好了（账户 交易时间 收入 支出 余额 对方账号 对方户名 开户行 摘要），
复制有内容的行 → 到资金台帐 **B 列**最下面「选择性粘贴 → 数值」。
- **用银行卡、信用卡付的**（支付方式不是零钱/余额）自动跳过——银行流水里已经有这一笔，不然会记两次；交易关闭、失败的也跳过；
- **零钱提现**记成微信账户的支出、**充值**记成收入；银行那边对应的一笔（对方是财付通/支付宝）在资金台帐 L 列选「账户互转」，两边抵成 0；
- 转入零钱通这类只在微信里面倒的跳过；
- 别的银行列顺序不一样的，在「自定义」那行填每样东西在第几列。

流水顺序不用管：**即时余额按交易时间先后算**，银行倒序导出（新的在上）、或者后来补粘前几个月的，余额照样对得上。

### 3. 手工记（现金、个人代付等）

资金台帐同一张表往下记一行：B 账户、C 日期、D 收入或 E 支出、H 对方户名（或 K 直接选往来单位）、J 摘要、需要的话 L 选收支项目。

### 4. 导发票

电子税务局 → 发票查询统计 → 导出（**销项、进项都导，5 家公司的都导**），打开导出的文件，切到「发票基础信息」那一页，
选中第 2 行起的明细（不要表头、不要最后的合计行）复制，粘到【发票导入】A 列最下面的空行。

## 四、自动认的规则

**往来单位**（资金台帐 P 列）：K 列手工选的 → 否则对方户名跟往来单位的名称/别名 1/别名 2 对上 → 否则对方户名是自家公司全称 → 否则对方账号对上。

**收支项目**（资金台帐 T 列），按顺序谁先有用谁：
1. L 列手工选的；
2. 对方是自家公司：同一家公司 → 账户互转，另一家 → 内部划转；
3. 往来单位绑定的收支项目；
4. 摘要关键词；
5. 对方是客户、钱是收进来的：这家公司以前收过这个客户的钱（或者「建账前已合作」）→ 续费，否则 → 新增（客户来款不看摘要关键词，摘要里写了「刻章」也按新增/续费算，要改在 L 列改）；
6. 都不是 → 空着，X 列提示 ✗，等你手工选。

**社保挂靠、费用类的手工筛选**：认不出的都是 ✗；另外国库扣款默认算税金，但会标 ⚠「税务扣款默认算税金」——国库扣的里面可能有社保、社保挂靠，筛一下 ⚠ 改过来就行。

支付宝、微信导出里打码的人名（比如「李*」「*丽」）按原样认，不会跟别的名字混。

> 「新增 / 续费」是**按公司分开算**的：客户第一次给中智优力打钱算中智优力的新增，后来第一次给另一家公司打钱，也算那家公司的新增。
> 要是你希望 5 家公司合起来算（第二家也算续费），跟我说一声改一下就行。

**所属公司**：资金台帐＝账户的所属公司；发票＝销方税号是自家的 → 销项，购方税号是自家的 → 进项，两边都是自家 → 内部开票。

**应付**：进项发票（计应付的）增加应付；付给供应商的成本费用、投资类款项冲应付。付税款、付工资这类对方不是供应商的付款不冲应付。

**应收**：销项发票增加应收；收到的收入类款项冲应收。所以**收了款没开票的客户，应收是负数**（提示「已收款未开票/预收」）；首页「客户欠款」只加正数。

**往来对账单跟应收应付汇总一个口径**：只算销项/进项发票、收入类收款、付给供应商的款、往来（借款押金）、内部划转；给这个人发工资、交税这类不算往来的不列。

**内部往来**：期初往来 ＋ 自家公司之间开的票 ＋ 互相转的钱，一起算谁欠谁。发票导入里自家之间的票两家的导出里都会有，只算一次。

## 六、跨年度怎么用

- **不用换本子**：资金台帐（6000 行）、发票导入（3000 行）一直往下记，报表顶上把年份换成 2027 就是 2027 年的；
  应收应付的「期初」自动等于上一年年底的余额，客户新增/续费也会看以前年份的记录。
- **快满了**（数据校验第 28、29 项会提醒）：在最后几行中间右键「插入」若干行，再把上面一行整行复制粘贴下来，各报表的范围会自动跟着变大。
- 想一年一本也可以：年底另存一份，清掉资金台帐、发票导入的数据，把各账户年底余额填成新期初、应收应付汇总的年底余额填进「期初往来」，
  老客户在往来单位「建账前已合作」填「是」。
