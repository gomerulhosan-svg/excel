## 二、两本怎么一起用

1. **两个文件放在同一个文件夹，文件名不要改。** 报表本是按文件名找录入本的。改了名，Excel 里「数据 → 编辑链接 → 更改源」重新指一下就行。
2. **日常在 ① 录入本里粘流水、粘发票、改 ✗，存盘。**
3. **看报表时打开 ② 报表本。** Excel 会提示「此工作簿包含到外部源的链接……」，点「**更新**」；WPS 点「**启用内容 / 更新链接**」。数就是 ① 最新存盘的。
   也可以先打开 ①、再打开 ②，两本都开着的时候，① 一改 ② 马上跟着变。

## 四、每月怎么做

### 1. 银行、微信、支付宝的流水

1. 网银 / 微信 / 支付宝导出流水文件，用 Excel 打开，**全选复制**；
2. 粘到这个账户的【流水N】表：第一次粘到 **A9**，以后粘到下面第一个空行。标题、表头、合计行一起粘进来没关系，会自动跳过；
3. 看第 3 行：「表头在第 X 行 → 日期=A 收入=B 支出=C 余额=D 对方户名=F 摘要=H ✓」就是认出来了；
4. 每一笔的结果在 U 列（√ / ⚠ / ✗ / 跳过），同时进【资金台帐】；
5. ✗ 的就在这一行 **V 列选往来单位、W 列选收支项目**（社保挂靠、费用类就在这里手工筛选）。也可以在资金台帐筛选 ✗，点「去改 →」跳过来。

**微信、支付宝**自动处理这几种：
- 用银行卡、信用卡、花呗付的（支付方式不是零钱/余额）**跳过**：银行流水里已经有这一笔，不然会记两次；
- 交易关闭、失败的**跳过**；
- **零钱提现**记成微信账户的支出（摘要关键词「提现」→ 账户互转），**充值**记成收入；银行那边对应的一笔（对方是财付通/支付宝）在银行的流水表 W 列选「账户互转」，两边抵成 0；
- 转入零钱通这类「不计收支」的**跳过**。

同一张流水表里不小心粘重了的，只算一次（U 列显示「跳过：粘重了」）。

### 2. 现金、个人代付

【手工记账】一笔一行：A 选账户、B 日期、C 收入或 D 支出、E 对方户名、F 摘要；G 往来单位、H 收支项目认得出就不用填。

### 3. 发票

电子税务局 → 发票查询统计 → 导出（**销项、进项都导，几家公司的都导**），打开后「发票基础信息」页第 2 行起的明细（不要表头、不要合计行）复制，粘到【发票导入】A 列最下面的空行。按税号自动认是哪家公司、销项还是进项。

## 五、流水表怎么认格式（万一认错了）

在前 40 行里找第一行同时有「日期/时间」和「金额/收入/支出/发生额/收支/借贷」的，当表头；再按表头文字认各列：

| 要认的 | 表头里的写法（先找到的算） |
|---|---|
| 日期 | 交易日期、记账日期、入账日期、日期 ……；都没有就用「交易时间」（带时分秒也行） |
| 收入 / 支出 | 收入金额、收入、**贷方发生额**、贷方金额、存入 / 支出金额、支出、**借方发生额**、借方金额、取出 |
| 金额＋收支标志 | 没有收入/支出两列时：金额、金额(元)、交易金额、发生额 ＋ 收/支、借贷标志、借/贷（微信、支付宝就是这种） |
| 余额 | 余额、账户余额 |
| 对方户名 / 账号 / 开户行 | 对方户名、对方名称、对方单位、交易对方…… / 对方账号、对方账户、对方卡号 / 对方开户行、对方开户机构、对方行名 |
| 摘要 | 摘要、交易类型、交易分类、动账类型、业务类型 ＋ 用途、附言、商品、商品说明、备注 |
| 收支方向 | 有「收入/支出」（或借方/贷方）两列时，按余额判断哪列是进账：大多数银行贷方＝进账；鄞州农商这种借方＝进账的，T 列自动显示「反向」 |

认错了：在第 6 行对应格子**填正确的列号**（A 列＝1，B 列＝2……），第 7 行「实际用」就变成你填的。表头不在前 40 行：U6 填表头在第几行。收支方向判断错了：T6 选「正常 / 反向」。

**余额核对**：同一时刻有几笔的（银行只给日期、微信商户收款和手续费同一分钟），按导出顺序排（倒序导出就倒着排）；带银行余额的，这笔的余额等于「之前 ＋ 这一笔」或「之前 ＋ 同一时刻全部」都算对上。

## 六、自动认的规则

**往来单位**：流水表 V 列手工选的 → 对方户名是自家公司全称 → 对方户名跟往来单位的名称 / 别名 1 / 别名 2 对上（括号全角半角、空格都不管）→ 对方账号对上。

**收支项目**，按顺序谁先有用谁：
1. 流水表 W 列手工选的；
2. 对方是自家公司：同一家公司 → 账户互转，另一家 → 内部划转；
3. 往来单位绑定的收支项目（税务银行类的单位，摘要里有关键词就先按关键词：国库扣的社保 → 人工-社保）；
4. 摘要关键词（客户来款不看关键词）；这次加了「印花税、税收 → 税金」「社保、公积金 → 人工-社保」；
5. 对方是客户、钱是收进来的：这家公司以前收过这个客户的钱（或者「建账前已合作」）→ 续费，否则 → 新增；
6. 都不是 → ✗，等你手工选。

**所属公司**：资金台帐＝账户的所属公司；发票＝税号对上的那家（销方是自家 → 销项，购方是自家 → 进项，两边都是 → 内部开票）。

**应收**＝销项发票 − 收到的收入类款项（收了款没开票的显示负数「已收款未开票/预收」）；**应付**＝计应付的进项发票 − 付给供应商的成本费用款；**其他往来**＝收支项目「往来」（借款、还款、押金）。往来对账单跟应收应付汇总一个口径。
