# A070 供销社多板块财务模板 · 设计和口径

> 用户原话：需要设置财务模板，资金台帐＋应收应付的跟进，需要自动出对账单。表格内是我需要的内容（查询、培训学校、为农服务中心、粮食烘干、粮食购销、供销社），
> 还要增加一个登记汇总表（在一个总表登记收支信息），然后自动拆分到这几个不同板块。不用跟进发票。一张表格处理，一个单位的业务板块不一样，按板块分类。
> 一个表作为录入，然后分类归档、分开查询，主要记录收支记录和应收应付。收支记录和应收应付可以分开 2 个表格登记（一个表格会很多列）。
> 用户原表：`../参考/用户原表.xlsx`。

## 0. 总原则（跟 A066 第二版一样）

1. 录入表只放录入列（＋最右边两列只给人看的显示列，别的公式不引用）。
2. 逐行计算放隐藏表 `_收`、`_往`，按「第 n 条」取数 `INDEX(录入表!$X$表头行:$X$1048576, n+1)`。
3. 查看表只用定义名称（`layout.NAMES`）做 SUMIFS/COUNTIFS；清单用隐藏列「排序键＋SMALL」或 `common.counter/kth`。
4. 名字做 SUMIFS/COUNTIFS 条件用 `esc()`；选择格空＝全部用 `layout.seg_crit()`（`"<>@@全部@@"`）。
5. 只用 Excel 2010 / WPS 都有的函数：不用 XLOOKUP/FILTER/UNIQUE/SORT/LET/IFS/MAXIFS/MINIFS/SWITCH/TEXTJOIN/CONCAT/INDIRECT/OFFSET/TODAY/NOW/AGGREGATE，
   不用任何数组写法（`MAX(INDEX(表达式,0))`、`SUMPRODUCT(MAX(…))` 都不行），make.check_formulas 会拦。
6. 每张查看表自己有起止黄格（FILL_SEL）；空着＝默认（起＝建账日 `P_建账日` 或 `P_年初`，止＝首页截止 `P_截止`），旁边显示实际用的值。

## 2. 收支项目的三个属性（基础资料④）

- 方向：收入 / 支出 / 双向。收入/支出栏都空、有数量×单价时，按方向决定算收入还是支出。
- 用途：普通 / 冲应收（收回欠款）/ 冲应付（支付欠款）/ 固定资产（买设备）/ 内部转账（账户之间倒钱：两行，一出一进，不算板块收支）。
- 库存：入库（粮食购进，加存量）/ 出库（粮食销售，减存量）/ 空。

## 3. 口径（隐藏表列名见 layout.SHOU_COLS / WANG_COLS）

| 数 | 取法（板块 p；空＝全部；日期段 [起,止]） |
|---|---|
| 收入、支出（板块） | `收_板块收入`、`收_板块支出`（有效、不含内部转账）按 收_板块、收_日期、（收_经手人）SUMIFS |
| 板块结余（到 d） | 板块期初结余（`板块_期初结余`）＋ Σ收_板块收入 − Σ收_板块支出（日期 ≤ d） |
| 账户余额（到 d） | `账户_期初余额` ＋ Σ收_净额（收_账户＝它，日期 ≤ d；含内部转账） |
| 粮食购进 数量 | Σ收_入库量 ＋ Σ往_入库量；金额 ＝ Σ收_支出（收_库存="入库"）＋ Σ往_金额（往_库存="入库"） |
| 粮食销售 数量 | Σ收_出库量 ＋ Σ往_出库量；金额 ＝ Σ收_收入（收_库存="出库"）＋ Σ往_金额（往_库存="出库"） |
| 粮食存量（到 d） | 板块期初存量 ＋ Σ入库量 − Σ出库量（两张表，日期 ≤ d） |
| 固定资产（到 d） | 板块期初固定资产 ＋ Σ收_固定资产 ＋ Σ往_固定资产（日期 ≤ d） |
| 应收余额（到 d） | Σ往_应收额 − Σ收_冲应收（板块或往来单位；日期 ≤ d） |
| 应付余额（到 d） | Σ往_应付额 − Σ收_冲应付 |
| 每笔赊账还没结的 | `往_未结`：截至 `P_截止`，同单位同类型按日期先进先出，用收回/付出的钱（＋负数的折让）冲；`往_逾期天数` ＝ 截止 − 约定日期 |
| 最近一次收/付款日 | `SUMIFS(收_日期, 收_往来单位, u, 收_用途, "冲应收"/"冲应付", 收_最新收付, 1)` |
| 最早没结的约定日 | `SUMIFS(往_约定日期, 往_往来单位, u, 往_类型, t, 往_最早未结, 1)` |
| 最近一笔赊账日 | `SUMIFS(往_日期, 往_往来单位, u, 往_类型, t, 往_最新发生, 1)` |

- `_往` 的先进先出、逾期、最新标记都按首页截止日（`P_截止`）算，跟进表就按这一天。
- 对账单：往来单位 u 的每一笔：
  - 应收应付登记的行：应收 → 「应收增加」；应付 → 「应付增加」。
  - 收支登记里往来单位＝u 的行：用途＝冲应收 → 「收款」＝收_冲应收；冲应付 → 「付款」＝收_冲应付；
    其他（普通、固定资产）＝当场结清（现结）：收入 → 应收增加＝收款＝收入；支出 → 应付增加＝付款＝支出（余额不变，只为把交易列全）；内部转账不列。
  - 期初余额 ＝ 起以前的应收（应付）余额。
- 板块表的清单：本板块的收支登记行（不含内部转账）＋ 应收应付登记行，按日期排（同一天收支在前）；
  结余只按收支登记行滚动；粮食存量两张表都算；赊账的行在「应收（赊）」「应付（赊）」列显示金额，收回/付出欠款的行显示负数。

## 4. 隐藏表

- `_参`：P_单位名称、P_建账日（空＝最早一笔）、P_账期、P_最后日期、P_截止、P_年度、P_年初、P_默认账户、P_截止年月。
- `_表`：板块_名称/期初结余/期初存量/期初固定资产，账户_名称/期初余额，项目_名称/方向/用途/库存，经手人_姓名，单位_名称/类型/账期/联系人/电话（逐行镜像，可能有空）；
  压紧的下拉清单（板块列表、账户列表、收支项目列表、经手人列表、往来单位列表；`_表!W1` 等是个数）。
- `_收`、`_往`：见 layout。排序键：收＝日期×10000＋n，往＝日期×10000＋5000＋n（同一天收支在前）。
