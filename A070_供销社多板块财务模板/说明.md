# A070 · 供销社多板块财务模板（资金台帐 ＋ 应收应付跟进 ＋ 对账单）

> **你说的：** 需要设置财务模板，资金台帐＋应收应付的跟进，需要自动出对账单。表格内是我需要的内容（查询、培训学校、为农服务中心、粮食烘干、粮食购销、供销社），
> 还要增加一个登记汇总表（在一个总表登记收支信息），然后自动拆分到这几个板块。不用跟进发票。一个单位的业务板块不一样，按业务板块分类；
> 一个表作为录入，然后分类归档、分开查询，主要记录收支记录和应收应付；收支记录和应收应付分开 2 个表格登记（一个表格会很多列）。

---

## 一句话

**一本表 `A070_供销社多板块财务模板.xlsx`。平时只录两张蓝色的表，其余全是自动的；哪里都可以插行、删行。**

| 平时录（蓝） | 干什么 |
|---|---|
| **收支登记**（登记汇总表） | 所有板块的每一笔钱都在这一张记：日期、**业务板块**、收支项目、摘要、往来单位、数量（KG）、单价、收入、支出、账户、经手人、备注。12 列，都从下拉选 |
| **应收应付登记** | 钱当时没收 / 没付的（赊销、赊购）：日期、业务板块、往来单位、应收 / 应付、业务内容、摘要、数量、单价、金额、约定收付款日期、经手人、备注 |

自动拆分、归档（绿）：

| 表 | 是什么 |
|---|---|
| **培训学校、为农服务中心、供销社** | 你原表的格式：日期｜摘要｜收入｜支出｜结余｜经手人。从两张登记表按板块自动拆出来，按日期排，结余自动滚 |
| **粮食烘干** | 你原表的格式：日期｜摘要｜客户名称｜烘干重量KG｜烘干单价｜收入｜支出｜结余｜经手人 |
| **粮食购销** | 你原表的格式：日期｜摘要｜客户名称｜购进数量KG｜购进单价｜销售数量｜销售单价｜粮食存量｜收入｜支出｜结余｜经手人；粮食存量自动滚（赊购赊销的也算） |
| **查询** | 你原表的格式：第 3 行黄格填 起始日期、截止日期、所属经营类别、经手人，就出 粮食购进、粮食销售、粮食存量、收入、支出、结余、固定资产、应收、应付；下面还有各板块一览、按月、收支明细、应收应付明细 |
| **资金台账** | 现金、银行日记账：每个账户期初、收入、支出、期末；逐笔带余额 |

往来（橙，自动）：

| 表 | 是什么 |
|---|---|
| **应收应付跟进** | 每个往来单位：赊了多少、收回 / 付了多少、还欠多少、**过期没有、过了几天**、最近一次收 / 付款是哪天；账龄（没到期、过期 1～30 天、31～90 天、90 天以上）；逾期的一笔一笔列出来，催款用 |
| **对账单** | 选往来单位（可再选板块、起止日期），自动出对账单：期初余额、每一笔（赊账、收款付款、当场结清的也列）、余额、合计，底下双方盖章签字，A4 横向直接打印 |

基础（灰，偶尔改）：**基础资料**（单位名称、建账日期、默认账期；业务板块的期初结余、期初粮食存量、期初固定资产；账户期初余额；收支项目；经手人）、**往来单位**（客户、供应商、联系人、电话、账期）。
另外【首页】有截止日期、关键数、各板块一览、提醒、各表入口、「常见情况怎么记」；【数据校验】列出录错的行。

## 常见情况怎么记

| 情况 | 记在哪 | 怎么记 |
|---|---|---|
| 收钱、付钱（当场结清） | 收支登记 | 一行：日期、业务板块、收支项目、摘要、收入或支出。粮食买卖、烘干按斤算的填数量、单价，**金额＝数量×单价**（金额空着也会按数量×单价算） |
| 卖出去没收钱（赊销） | 应收应付登记 | 一行「应收」：往来单位、业务内容、数量单价或金额；可以填约定收款日期，不填按账期（默认 30 天） |
| 买进来没付钱（赊购） | 应收应付登记 | 一行「应付」 |
| 收回以前的欠款 | 收支登记 | 收支项目选「收回欠款」，**往来单位选欠钱的那家**，业务板块选当初赊销的板块 |
| 付掉欠人家的钱 | 收支登记 | 收支项目选「支付欠款」，往来单位选那家 |
| 折让、少收、抹零 | 应收应付登记 | 同一个单位记一行负数 |
| 现金存银行、银行取现 | 收支登记 | 记两行「内部转账」：转出的账户记支出、转入的账户记收入，金额一样；不算收支 |
| 板块之间调钱 | 收支登记 | 记两行「板块调拨」：调出的板块记支出、调入的板块记收入 |
| 买设备、房屋 | 收支登记（赊购的在应收应付登记） | 收支项目选「购置固定资产」，查询里「固定资产」就有了 |
| 建账以前的老欠款 | 应收应付登记 | 记一行，摘要写「期初余额」 |
| 跟对方对账 | 对账单 | 选往来单位、起止日期，打印出来双方签字 |

## 怎么算的（几个容易问的）

- **结余**＝板块期初结余＋收入－支出（钱进出），按收支登记算；赊账不动结余，收回欠款、付掉欠款时才动。所以各板块表的结余就是这个板块手上的钱。
- **应收、应付**：应收应付登记里赊出去 / 赊进来的，减去收支登记里「收回欠款」「支付欠款」的。**先欠先还**：收回来的钱先冲最早那笔，所以每一笔还欠多少、过期几天都算得出来（应收应付登记最右边「这笔还没结的」）。
- **过期（逾期）**：约定收付款日期（没填＝登记日期＋账期）早于首页截止日期、还没结清的。
- **粮食存量**＝期初存量＋购进－销售（收支登记和应收应付登记都算，按 KG）。
- **固定资产**＝期初固定资产＋买设备的钱（现金买的、赊购的都算）。
- **收入、支出**是钱进钱出（资金台帐的口径），所以收回欠款、借款、板块调拨也在里面；【首页】关键数下面一行单独列出了「本年收入里有：收回欠款、借款、板块调拨」「支出里有：支付欠款、还借款、板块调拨、买固定资产」，这些不是经营收支。
- **对账单**里当场结清的买卖也列出来（增加和收款 / 付款同时记，余额不变），这样跟对方的每一笔交易都对得上。

## 插行删行

- 两张登记表、基础资料、往来单位**哪里都可以插行、删行、排序（整行一起动）**，各表都不会出错（我在 LibreOffice 里逐张试过 30 多种插、删、排序：插一行录一笔，各表跟着变；删掉，回到原样；整片删光再录也不坏）。
- 插进来的行，最右边两列「本账户结余」「这一行的问题」可能是空的（从上一行往下拉一下就有），不影响任何汇总。
- 绿色、橙色的表和首页是自动的，有保护（没有密码），只有黄格子能改。
- 基础资料里几块是上下排的，在一块里插整行、删整行只动这一块。**改了板块名、收支项目名**，用「查找替换」把两张登记表里的旧名字也改掉（不然那些行就不算这个板块了，【数据校验】会提醒）。
- 容量：收支登记 5000 笔、应收应付登记 2000 笔、往来单位 500 个、业务板块 15 个、收支项目 120 个。**建议一年一本**，年底另起一本，期初余额填上一年的期末；超了【数据校验】和首页都会提醒。

## 示例数据

模板里先放了你原表的几行（粮食烘干：杨庆火 2000KG×200、燃气充值、电费充值；粮食购销：收购稻谷、销售稻谷、人工工资、编织袋、稻壳、碎米），
另外加了一笔赊销、一笔赊购、一笔收回欠款，演示应收应付和对账单。示例行是灰底、备注里写着「示例」，正式用时整行删掉就行。

**要你确认一下**：粮食烘干那行 2000KG × 单价 200 ＝ 400,000 元，跟粮价 2.46 元/KG 比太大了。烘干单价 200 是「元/吨」吧？
如果是按吨报价，收支登记里单价填 0.2（元/KG），或者直接在收入栏填金额（400 元）。
