## 提速（opt）

用户原话：「帮我优化一下A075的这个模板，录入数据及保存时非常卡顿，接近死机了」。
规矩：**不改功能、不改任何报表结果**（同样的录入，所有账、表、凭证、报表每格结果一样），不改容量；Excel 2010 / WPS 能用
（不用 FILTER / XLOOKUP / MAXIFS / TEXTJOIN / IFS / LET / 动态数组、INDIRECT、TODAY / NOW；OFFSET 只在下拉名称里）。

### 病根

原来录任何一格，LibreOffice / Excel 要重算 37～40 万个公式（静态扇出，见下），而且其中几千个各自把 1.8 万行【记账分录】整列翻一遍：
科目余额表按 `$A7&"*"` 模糊 SUMIFS、明细账 SMALL＋MATCH、记账分录 / _凭证索引用 `INDEX(整列,第几笔)` 取流水（一格变、整列的公式都脏）、
现金流水总表余额和合并分组 O(n²)、往来余额表 / 月末结转 / 经营报表按日期＋科目开头整列扫。录一格≈整本重算一遍。

### 怎么核对的（scratchpad `a075/t/opt/`，没进仓库）

- `scen.py`：两套满数据场景（A062 样例数据换成美元口径）。A＝2026 全年 516 笔流水（美元 / FBC / 人民币，各类别），采购 / 领用 / 产量 / 销售 / 工资 / 资产 / 手工凭证各几十行，报表 2026-10，明细账 1002；
  B＝2026-06～2027-03 跨年 396 笔，报表 2027-02，明细账 5602，期末调汇从 2026-10 开，损益科目有期初。两套都填了基础资料 J5:J7。
- `runbuild.py 生成脚本目录 A|B 输出 --share --calc`：同一套场景分别填进「提速前」（`base_gen/`）和「提速后」，显示隐藏列后 LibreOffice 关多线程整本重算；
  `cmpvals.py 前_算数 后_算数 --hidden-from 前 后`：所有表（含隐藏表、隐藏列）**每个公式格**比值。
- 结果：每做一项（s1 科目余额表、s2/3 明细账＋取流水、s4 现金流水、s5～s8 其余、s9 凭证汇总 / 记账凭证、final 整套）A、B 两套各比一次，
  **全部 0 处不一致**（652,025 格两边都有；提速后多出来的 104,477 格是新辅助列 / 新校验行）。空模板：只差资金账户余额表 K6/K7/K25（上面说的）。
- 空模板成品 LibreOffice 重算 756,502 个公式，0 报错。
