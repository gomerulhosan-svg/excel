## 二、每天录什么

### 1）资金台帐 —— 混合录入、即时余额（费用也在这里记）

版式照你截图那种：顶上一条汇总（选月份 → 本月收入 / 本月支出 / 上月结余 / 本月结余 / 当前总余额），
下面绿色「＋ 收入」、黄色「＋ 支出」色带。**收入、支出记在同一张表里，按发生顺序一行一笔**：

| 列 | 填什么 |
|---|---|
| 日期 / 账户 | 账户从下拉选：收款码、农业工账、农业银行、工商银行、信用社、邮政银行、现金、微信、支付宝（在基础资料里能加） |
| 收支项目 | 下拉选。**选了客户＋填收入 → 自动算「客户回款」；选了供应商＋填支出 → 自动算「供应商付款」；选了费用项目 → 自动算「费用支出」**，这三种可以不选。反过来的（付给客户的钱、厂家给的钱）一定要自己选，表会提醒 |
| 摘要 | 随便写（原来费用明细的「支出明细」就搬在这一列） |
| 收入金额 / 支出金额 | 只填一边 |
| 账户余额 / 总余额 | **自动**：这个账户逐行滚出来的余额、所有账户合计余额 |
| **客户 / 供应商 / 费用项目 / 报销人** | 四个**筛选列**。费用项目就是原来费用明细的「支出类别」；报销人随手填名字。点表头筛选按钮选一个客户，就是他的全部收付款；选一个报销人，就是他报的全部费用 |
| 备注 / 校验 | 校验自动：`√`，或者告诉你哪里不对（没选客户、收入支出填反、金额是文本、日期不对、账户余额成负数、**没填金额**……） |

**收付款冲减就靠「客户」「供应商」两列：**
收客户的钱选上客户 → 【总览汇总】「已付款金额」、【收付款明细】、【客户对账单】同时变；
付厂家的钱选上供应商 → 【供应商对账单】、【资产负债表·应付账款】同时变。**不用在别处重复登记。**

**费用**：花钱的记一行支出、选费用项目、填报销人 → 【全量费用明细总表】【费用汇总】【利润表】同时变。报销给员工也是这样记一行（账户选你实际付钱的账户）。

**收款码到账**（给【收款码到账对账】用）：
- 客户扫码付款：账户「收款码」，照常记收入（选客户）；
- 钱到了银行：记**两行「内部转账」**——收款码一行支出（到账金额）、农业银行一行收入（同样金额），日期写收款那天；
- 手续费：收款码一行支出，收支项目「费用支出」，费用项目「手续费」（可以每天记，也可以月底记一笔合计）。
这样收款码账户的余额就是「还没到账的钱」，对账表上「差额」＝手续费、「还没记的手续费」为 0 就对上了。

13 个收支项目，每个都写了「去向」（落到报表哪一行），在【基础资料】里看得到、能加：

| 收支项目 | 去向 | | 收支项目 | 去向 |
|---|---|---|---|---|
| 客户回款 / 客户退款 | 冲客户未付货款 | | 股东投入 / 股东提取 | 所有者权益 |
| 供应商付款 / 供应商退款 | 冲欠厂家货款 | | 借入款项 / 归还借款 | 短期借款 |
| 厂家返利 | 利润表·其他业务收入 | | 内部转账 | 不进报表（转出、转入各记一行） |
| 费用支出 | 按费用项目进利润表 | | 其他往来 | 押金等，进其他应收/应付 |
| 其他收入 | 利润表·营业外收入 | | | |

> **已经搬进资金台帐的：** 原来【收付款明细】里手工登的 117 笔客户收款（金额一分没变，合计 3,869,309.69），
> 和你补充的费用明细 367 笔（收支项目「费用支出」，**金额空着**——你原表的「支出金额」整列是空的）。
> 两批按日期排在一起，同一天先收款后费用。费用明细「账户」写「拼多多」「淘宝」「未付」的，不是资金账户，账户留空、原文字写进了备注。

### 2）出库明细、存条明细（原表，照原来录）

列没变。客户、商品两列有**下拉**（名字写错一个字，所有按名字汇总的数都会漏）；日期列有「不在本年度」提醒；
金额公式铺到了 3000 行 / 1000 行；序号改成公式（你上一版里把重号、跳号重新排过，现在自动排）；
单价跟商品档案「参考售价」差 3 倍以上的，单价格子会标红（多半是把金额填进了单价）。
赠品（有数量没单价）照原来那样录：收入是 0，成本照算。

### 3）采购进货（新）

从厂家进货一个商品一行：供应商、商品从下拉选，数量 × 进价自动出金额；**厂家搭赠的货填「赠品数量」**，只加库存不加货款；退货数量填负数。
付货款去资金台帐记一笔、选上供应商。

### 4）报损明细台账（原表，一年一张）

列还是原来的：所属公司、产品名称、规格型号、报损数量、单位、产品单价、报损金额（自动＝数量×单价）、报损原因、备注，**前面多一列「月份」**（填 1～12）。
- 新的一条报损往下面空行记，填上月份。同一个月同一个商品可以只记一行，数量像原来一样写 `=5+27+16` 累加；也可以每次一行。
- 产品名称从下拉选（就是【基础资料·商品档案】的「报损表品名」），所属公司从供应商下拉选。
- **按月看**：点「月份」表头的筛选按钮选那个月，第 4 行「表头筛选后的合计」跟着变；或者在第 3 行黄格子选月份、公司，右边直接写出「共几行、数量多少、金额多少」。
- 右边「校验」列：没填月份、月份不是 1～12、数量写成「2箱」这种文字的标 ✗（这些行哪个月都不算）；没单价、没所属公司、品名不在商品档案里的标 ⚠。
- 原来 6、7、8 月三张表里**填了数量的 45 行**都搬过来了（数量里的累加公式原样保留），只列了商品没填数量的空模板行没搬。

## 八、口径

- **收入**＝出库明细的领用金额，按出库日期归月（和原来「已领用金额」同一个数）。
- **存条**：客户付的存条款在资金台帐记「客户回款」，出库时才算收入；没用完的部分在资产负债表上是「预收账款（客户存条/预存款）」。
- **成本**：全月一次加权平均——当月（上月结存＋本月进货）的平均进价 × 出库数量；当月库存是负的但有进货，就用当月进货均价；都没有才用参考进价估算。
- **报损**：报损明细台账里的金额（数量×单价，单价是进价）按「月份」全额进利润表「商品报损损失」，并按「每件瓶数」折成件冲减公司库存（单位写「箱」「件」的按件算）。
- **费用**：只看资金台帐的「费用支出」，按付款日期归月（记账日期就是费用日期）。
- **返利、营业外收支、投入、提取、借款**：都从资金台帐按收支项目取。
- **资产负债表**由期初数加上全年流水滚出来，结构上保证平衡；对不上的（没登记的客户、没分类的收支、没配对的内部转账……）单独列在附注里。

## 十、兼容性

- 只用了 Excel 2010 起就有的函数（最新日期用 `AGGREGATE`，没用 2019 才有的 `MAXIFS`），
  **没用 FILTER / UNIQUE / XLOOKUP 这类动态数组，也没有要按 Ctrl+Shift+Enter 的数组公式**，老版 WPS、Excel 2010/2016 都能用。

- 成品没让 LibreOffice / WPS「另存为」过；算好的数已经写在文件里，手机上预览也能看到，
  Excel / WPS 打开时会自动再全部算一遍（几秒钟）。
