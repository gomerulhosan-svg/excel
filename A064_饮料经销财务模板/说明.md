## 一、这套表怎么转

```
 每天录 ──┬─ 资金台帐 ────── 收钱付钱一笔一行（混合录入），右边自动滚出账户余额、总余额
          │                  └ 后面三列：客户 / 供应商 / 费用项目（筛选列）
          ├─ 出库明细 ────── 客户领货（原表）
          ├─ 存条明细 ────── 客户存条（原表）
          ├─ 采购进货 ────── 从厂家进货（新）
          ├─ 全量费用明细总表 ─ 费用报销（你补充的表，原格式）
          └─ 每月报损表 ──── 过期报损（原表，一月一张）
                 │
                 ▼  全自动
   总览汇总（原表）  ← 已领用取出库明细；已付款直接从资金台帐里「选了这个客户的收款」冲减
   商品库存（原表）  ← 每个客户每个商品的存条结余，组合自动列出，不用手工加行
   收付款明细（原表）← 从资金台帐自动提取：左边客户收款，右边付厂家的钱（都按日期排）
   客户查询（原表）  ← 修好了（原来一个商品都列不出来）
   收付款汇总 / 客户对账单 / 供应商对账单（新，版式照客户查询）
   公司库存 / 成本计算（新）← 进货－出库－报损，全月一次加权平均算成本
   费用汇总 / 利润表 / 资产负债表（新）
   数据校验（新）← 所有「会让报表算错」的地方一表数出来
```

打开先看【首页】：关键数（本年销售额、毛利、净利润、资金余额、客户欠款/预存、欠厂家、待改项）＋ 每张表的跳转链接。

## 二、每天录什么

### 1）资金台帐 —— 混合录入、即时余额

版式照你截图那种：顶上一条汇总（选月份 → 本月收入 / 本月支出 / 上月结余 / 本月结余 / 当前总余额），
下面绿色「＋ 收入」、黄色「＋ 支出」色带。**收入、支出记在同一张表里，按发生顺序一行一笔**：

| 列 | 填什么 |
|---|---|
| 日期 / 账户 | 账户从下拉选：收款码、农业工账、农业银行、工商银行、信用社、邮政银行、现金、微信、支付宝（在基础资料里能加） |
| 收支项目 | 下拉选。**选了客户＋填收入 → 自动算「客户回款」；选了供应商＋填支出 → 自动算「供应商付款」；选了费用项目 → 自动算「费用支出」**，这三种可以不选。反过来的（付给客户的钱、厂家给的钱）一定要自己选，表会提醒 |
| 摘要 | 随便写（付款人、货款说明都写这里） |
| 收入金额 / 支出金额 | 只填一边 |
| 账户余额 / 总余额 | **自动**：这个账户逐行滚出来的余额、所有账户合计余额 |
| **客户 / 供应商 / 费用项目** | 三个**筛选列**，都有下拉。点表头筛选按钮选一个客户，就是他的全部收付款 |
| 校验 | 自动：`√`，或者告诉你哪里不对（没选客户、收入支出填反、金额是文本、日期不对、账户余额成负数……） |

**收付款冲减就靠「客户」「供应商」两列：**
收客户的钱选上客户 → 【总览汇总】「已付款金额」、【收付款明细】、【客户对账单】同时变；
付厂家的钱选上供应商 → 【供应商对账单】、【资产负债表·应付账款】同时变。**不用在别处重复登记。**

14 个收支项目，每个都写了「去向」（落到报表哪一行），在【基础资料】里看得到、能加：

| 收支项目 | 去向 | | 收支项目 | 去向 |
|---|---|---|---|---|
| 客户回款 / 客户退款 | 冲客户未付货款 | | 股东投入 / 股东提取 | 所有者权益 |
| 供应商付款 / 供应商退款 | 冲欠厂家货款 | | 借入款项 / 归还借款 | 短期借款 |
| 厂家返利 | 利润表·其他业务收入 | | 内部转账 | 不进报表（转出、转入各记一行） |
| 费用支出 | 按费用项目进利润表 | | 其他往来 | 押金等，进其他应收/应付 |
| 其他收入 | 利润表·营业外收入 | | **报销付款** | 付费用明细里登记过的费用，只冲「应付费用」 |

> **原来【收付款明细】里手工登的 117 笔客户收款，已经按日期排好整体搬进了资金台帐**（金额一分没变，合计 3,869,309.69），
> 那 59 格写成「2026.6.25」这种文字的日期都换成了真日期。

### 2）出库明细、存条明细（原表，照原来录）

样子没变。补了几样：客户、商品两列加了**下拉**（名字写错一个字，所有按名字汇总的数都会漏）；日期列加了「不在本年度」提醒；
金额公式铺到了 3000 行 / 1000 行；出库明细 C 列原来**表头是空的**，补上了「客户名称」；
单价跟商品档案「参考售价」差 3 倍以上的，单价格子会标红（多半是把金额填进了单价）。
赠品（有数量没单价）照原来那样录：收入是 0，成本照算。

### 3）采购进货（新）

从厂家进货一个商品一行：供应商、商品从下拉选，数量 × 进价自动出金额；**厂家搭赠的货填「赠品数量」**，只加库存不加货款；退货数量填负数。
付货款去资金台帐记一笔、选上供应商。

### 4）全量费用明细总表（你补充的表，原格式）

跟你原来一样一笔一行：日期、支出类别、支出明细、报销人、支出金额、账户、备注。表头、列宽、配色都没动，
日期原来是「2026.6.4」这种文字，换成了真日期但**显示还是 2026.6.4**；右边加了一列「校验」。
- **这里记的费用直接进【费用汇总】和【利润表】**（按支出类别；你用的 21 个类别都搬进了【基础资料·费用项目】，每个标好了是销售/管理/财务费用）。
- 钱实际付出去的时候（报销给员工、付之前「未付」的），在资金台帐记一笔，收支项目选「**报销付款**」——只冲应付，不会重复算费用。
  还没付的部分在资产负债表上是「**应付费用**」。
- 同一笔费用只在一个地方记：记了这张表，就别在资金台帐再选「费用支出」。
- 你原文件里的 4 张汇总（费用总览仪表盘 / 月度费用查询 / 按支出类别汇总 / 按报销人汇总）合并进了【费用汇总】：
  按类别×月份、按利润表归类小计、**按报销人×月份**（名字自动列出）。原来的「月度费用查询」用的是要按 Ctrl+Shift+Enter 的数组公式，一条都列不出来。

### 5）收款码到账对账（你补充文件里的 Sheet1，原样）

收款码收款 vs 农业银行实际到账，差额就是收款码手续费（约 0.3%）。右边算好了 **6 月手续费合计 952.09 元**，
并提示「资金台帐里还没记」。每月把手续费合计在资金台帐记一笔（账户＝收款码，收支项目＝费用支出，费用项目＝手续费），资金余额才等于银行实际到账。

### 6）报损（原表，每月一张）

照原来每月一张填。新的一个月：复制上个月那张表、改名（如「2026年10月报损」），再到【基础资料·报损月表清单】对应月份写上表名，
汇总、利润表、公司库存就都认了。已经替你建好了一张空白的【2026年9月报损】。「所属公司」下拉现在跟着【基础资料·供应商】走。

**② 利润表的成本现在是按「参考进价」估算的**（利润表上「其中：按参考进价估算的」那一行）。
参考进价是用你报损表里的每瓶单价 × 每件瓶数推出来的（例如大东鹏 3.23×24＝77.52 元/件），在【基础资料·商品档案】里，可以直接改。
**有 11 个商品没有参考进价，成本按 0 算，毛利会虚高**：小果之茶、1L果之茶、港式奶茶、330大咖、330海岛椰、东鹏椰子水、555椰子水、九制陈皮、小焙好茶、1L焙好茶、大鹏
——这些商品的销售额一共 355,179.70（利润表「另：没有进价、成本按 0 算的销售额」那一行）。把进价填上，或者录了真实进货，成本就准了。

**③ 利润表的费用是 0**：资金台帐里还没有费用，补充的费用明细表没金额（见第五节第 10 条）。

按现在的数：本年销售额 1,707,307.70，成本（估算）1,135,808.77，报损 17,655.22，净利润 553,843.71——
**等进价、费用补齐后会往下走不少**。【数据校验】现在有 2 项 ✗（结存为负、没有进价，都是进货没录造成的）和 8 项 ⚠ 提醒。

## 七、口径

- **收入**＝出库明细的领用金额，按出库日期归月（和原来「已领用金额」同一个数）。
- **存条**：客户付的存条款在资金台帐记「客户回款」，出库时才算收入；没用完的部分在资产负债表上是「预收账款（客户存条/预存款）」。
- **成本**：全月一次加权平均——当月（上月结存＋本月进货）的平均进价 × 出库数量；当月库存是负的但有进货，就用当月进货均价；都没有才用参考进价估算。
- **报损**：报损表里的金额（数量×单价，单价是进价）全额进利润表「商品报损损失」，并按「每件瓶数」折成件冲减公司库存（单位写「箱」「件」的按件算）。
- **费用**：全量费用明细总表（按登记日期，权责发生）＋ 资金台帐里直接记的「费用支出」；已登记没付的是「应付费用」。
- **返利、营业外收支、投入、提取、借款**：都从资金台帐按收支项目取。
- **资产负债表**由期初数加上全年流水滚出来，结构上保证平衡；对不上的（没登记的客户、没分类的收支、没配对的内部转账……）单独列在附注里。

## 八、容量、新年度、插行删行

| 表 | 容量 |
|---|---|
| 资金台帐 / 出库明细 | 各 3,000 行 |
| 存条明细 / 采购进货 / 全量费用明细总表 | 1,000 / 1,500 / 2,000 行 |
| 客户（总览汇总） / 商品 / 供应商 / 账户 | 300 / 100 / 50 / 20 个 |
| 商品库存「客户+商品」组合 | 600 个（现在 271 个） |
| 对账单明细 | 每次 299 笔（超了会提示缩短日期） |

**插行删行**：明细表里**删掉**一行没问题（各种汇总会跟着对上，已经实测过）；**新记录请往下面的空行填**，
别在中间插行——插出来的行没有公式，那一行不会进报表（【数据校验】会报「有金额却没有公式的行」，把上一行的公式往下拖一格就好）。
基础资料各块并排放着，也请只往空行填、不要插删行。

**一年一套**：新的一年另存一份，把【基础资料】的会计年度改成新年份，清空各录入表；
上年【总览汇总】的「未付货款」抄到「期初欠款」列，资金账户余额抄到「年初余额」，
公司库存结存抄到商品档案的期初库存，客户没提完的存条在存条明细里记一笔「上年结转」。

## 九、兼容性

- 只用了 Excel 2010 起就有的函数（最新日期用 `AGGREGATE`，没用 2019 才有的 `MAXIFS`），
  **没用 FILTER / UNIQUE / XLOOKUP 这类动态数组，也没有要按 Ctrl+Shift+Enter 的数组公式**，老版 WPS、Excel 2010/2016 都能用。
- 成品没让 LibreOffice / WPS「另存为」过，格式就是原表的格式；算好的数已经写在文件里，手机上预览也能看到，
  Excel / WPS 打开时会自动再全部算一遍（几秒钟）。
