## 二、每天录什么

### 1）资金台帐 —— 混合录入、即时余额（你要的核心）

版式照你截图的那种：顶上一条汇总（选月份 → 本月收入 / 本月支出 / 上月结余 / 本月结余 / 当前总余额），
下面绿色「＋ 收入」、黄色「＋ 支出」两列色带。**收入、支出记在同一张表里，按发生顺序一行一笔**：

| 列 | 填什么 |
|---|---|
| 日期 / 账户 | 账户从下拉选（收款码、农业工账、现金、微信、支付宝、银行卡，可在基础资料里加） |
| 收支项目 | 下拉选；**选了客户/供应商/费用项目的可以不选，会自动认**（选客户＋收入→客户回款，选供应商＋支出→供应商付款，选费用项目→费用支出） |
| 摘要 | 随便写 |
| 收入金额 / 支出金额 | 只填一边 |
| 账户余额 / 总余额 | **自动**：这个账户逐行滚出来的余额、所有账户合计余额 |
| **客户 / 供应商 / 费用项目** | 三个**筛选列**，都有下拉。表头有筛选按钮，点「客户」列选一个人，就是他的全部收付款 |
| 备注 | 随便写 |
| 校验 | 自动：`√` 或者告诉你哪里不对（没选客户、收入支出填反、日期不是真日期、账户余额成负数……） |

**收付款冲减就是靠「客户」「供应商」这两列：**
收客户的钱选上客户 → 【总览汇总】他的「已付款金额」、【收付款明细】、【客户对账单】同时跟着变；
付厂家的钱选上供应商 → 【供应商对账单】、【资产负债表·应付账款】跟着变。**不用再在别处重复登记。**

收支项目一共 13 个，每个都写了「去向」（落到报表哪一行），在【基础资料】里能看到、能加：

| 收支项目 | 去向 | | 收支项目 | 去向 |
|---|---|---|---|---|
| 客户回款 / 客户退款 | 冲客户未付货款 | | 股东投入 / 股东提取 | 所有者权益 |
| 供应商付款 / 供应商退款 | 冲欠厂家货款 | | 借入款项 / 归还借款 | 短期借款 |
| 厂家返利 | 利润表·其他业务收入 | | 内部转账 | 不进报表（转出、转入各记一行） |
| 费用支出 | 按费用项目进利润表 | | 其他往来 | 押金等，进其他应收/应付 |
| 其他收入 | 利润表·营业外收入 | | | |

费用项目 18 个（工资、运费油费、仓库租金、手续费、税费……），每个都标了是销售费用、管理费用还是财务费用。

> **原来【收付款明细】里手工登的 117 笔客户收款，已经按日期排好整体搬进了资金台帐**（金额一分没变，合计 3,869,309.69），
> 那 60 格写成「2026.6.25」这种文字的日期都转成了真日期。

### 2）出库明细、存条明细（原表，照原来录）

样子没变。补了三样：客户、商品两列加了**下拉**（名字写错一个字，所有按名字汇总的数都会漏）；
金额公式铺到了 3000 行 / 1000 行；出库明细 C 列原来**表头是空的**，补上了「客户名称」。

赠品（有数量没单价）照原来那样录就行：收入是 0，成本照算。

### 3）采购进货（新）

从厂家进货一个商品一行：供应商、商品从下拉选，数量 × 进价自动出金额；**厂家搭赠的货填「赠品数量」**，只加库存不加货款；退货数量填负数。
付货款去资金台帐记一笔、选上供应商。

### 4）报损（原表，每月一张）

照原来每月一张填。新的一个月：复制上个月那张表、改名（如「2026年10月报损」），再到【基础资料·报损月表清单】对应月份写上表名，
汇总、利润表、公司库存就都认了。已经替你建好了一张空白的【2026年9月报损】。

## 七、口径

- **收入**＝出库明细的领用金额，按出库日期归月（和原来「已领用金额」同一个数）。
- **存条**：客户付的存条款在资金台帐记「客户回款」，出库时才算收入；没用完的部分在资产负债表上是「预收账款（客户存条/预存款）」。
- **成本**：全月一次加权平均——当月（上月结存＋本月进货）的平均进价 × 出库数量；当月没货可算就先用参考进价估算。
- **报损**：报损表里的金额（数量×单价，单价是进价）全额进利润表「商品报损损失」，并按「每件瓶数」折成件冲减公司库存。
- **费用、返利、营业外收支、投入、提取、借款**：都从资金台帐按收支项目取。
- **资产负债表**由期初数加上全年流水滚出来，结构上保证平衡；对不上的（没登记的客户、没分类的收支、没配对的内部转账……）都单独列在附注里。

- 只用了 Excel 2010 起就有的函数，外加 `MAXIFS`（WPS 2019、Excel 2019/365 都有）。
