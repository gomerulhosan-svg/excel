## 0. 一句话

**平时只录 6 张蓝表**：【资金台帐】（所有账户的每一笔钱，含「老板垫付」这种不是现金的账户、员工报销按报销人＋报销项目）、
【进货登记】（一车一行：货款＋运费）、【销售台账】（一车一行：货款＋我方运费）、【生产日报】（一天一产品一行：产量、废料、12 个原料槽）、
【工资表】（一人一月一行）、【发票登记】（真开出、收到的票），偶尔用【手工凭证】调账。
**全自动出**：记账凭证（一张 A4 两张，可打印）、科目余额表、资产负债表、利润表、现金流量表、进销存、生产成本（每吨成本拆项）、
借款利息、垫付明细（按月打印＋补票跟进）、报销统计、资金日报月报、费用统计、客户/供应商往来、对账单、发票跟进、数据校验、首页。

## 1. 口径（定死的）

| 事项 | 口径 |
|---|---|
| 会计制度 | 小企业会计准则科目（损益 5 字头）；**表结法**（不出结转损益凭证，资产负债表未分配利润＝年初＋本年利润－利润分配） |
| 增值税 | 参数「纳税人类型」默认**一般纳税人**：录入一律录**含税金额**＋**票种**，隐藏层价税分离（专票按票种税率抵进项；普票/无票/待补票全进成本）；销售按销项税率（13%）分出销项。小规模：进项全进成本，销售按征收率。 |
| 进货运费 | 进**原材料成本**（并进该原料当月加权平均） |
| 销货运费 | 按用户「运费要记在成本中」默认进 **5401 主营业务成本-销货运费**；参数可切成 5601 销售费用-运输费（小企业准则的严格写法）。每吨成本分析里都单列。 |
| 存货计价 | 原料、产品都按**月末一次加权平均**（同一品种：(月初额＋本月入额)/(月初量＋本月入量)）；领光时用余额兜底，不留尾差 |
| 生产成本 | 品种法：直接材料按生产日报每行的产品归集；**制造费用（含生产工资、水电供热、折旧、建厂摊销……）按「产量吨×分摊系数」分到各产品**；当月一吨没产 → 制造费用整月留到下月；不算在产品 |
| 废料（二次过滤） | 当成「回收料」放原料档案：产出按**定额单价**（默认 0）进回收料库存，同时从主产品成本里扣；回炉投料按回收料加权单价出库；卖掉走销售台账（其他业务收入/成本） |
| 建厂费用 | 收支类别科目＝1801 长期待摊费用的（环评、认证、厂房改造……）**每笔自动从「开始摊销月」起按 N 个月平均摊**（开始月＝MAX(投产月, 付款次月)；N 默认参数 36，类别可单设），摊进 制造费用-建厂费用摊销（类别可设管理费用）。建账前已花的放期初。 |
| 设备 | 收支类别「机械设备费」→ 1601 固定资产；**另在【固定资产】登卡片**，卡片只管折旧（取得次月起提，按部门进 制造费用/管理费用）；数据校验比「卡片原值」和「账上 1601」 |
| 借款、垫付、利息 | 出借人（银行、个人、合伙人、老板）建在【往来单位】（类型＝出借人），填年利率、计息天数基数（360/365）。本金进出：资金台帐「借款到账/还借款本金/投资款」行（往来单位＝出借人）、**老板垫付账户的每一行**、基础资料「建账前借款明细」。**按日单利、算头不算尾，每月末计提**：借款（含垫付）→ 借 财务费用-利息支出 贷 应付利息；投资款（填了投资年利率的）→ 借 利润分配-应付利润 贷 应付利润（不进费用、不进每吨成本）。付息冲应付利息；出借人没填利率的，付息直接进财务费用。 |
| 老板垫付 | 【基础资料·账户】加类型「垫付」的账户（如「老板垫付」，填垫付人＝往来单位里的出借人）。老板个人掏钱的每一笔都在资金台帐这个账户记一行，**类别选真实用途**（伙食费、员工报销……）；账户余额是负数＝公司欠老板。公司还钱：银行行和垫付行各记一行「还垫付款」（像内部转账一样两行对冲）。 |
| 员工报销 | 不另开表：资金台帐类别「员工报销」，**报销人、报销项目必填**；科目按【报销项目】（材料→机物料、加油→车辆费、日常用品→办公费……）；按报销人×报销项目统计 |
| 跨月费用（所属月份） | 资金台帐「所属月份」跟付款月份不一样的费用（9 月电费 10 月付）→ 付款凭证记 其他应付款-跨月费用，另在所属月份月末自动出一张「费用归属」凭证（借 费用 贷 其他应付款-跨月费用）；所属月份早于建账月的按建账月 |
| 现金 | 现金流量表的现金＝账户类型 现金/银行/微信支付宝（1001/1002/1012）；**承兑汇票（1121）、老板垫付（2241）不是现金**；承兑到期/贴现入账、还垫付款用专门类别，现金那一行进现金流量表 |
| 凭证 | 每笔业务一张：资金台帐一行一张（有跨月的再加一张归属凭证）、进货一车一张、销售一车一张、手工凭证按组号；月末自动：领料、制造费用分配、完工入库（含废料扣）、销售成本、折旧、建厂摊销、工资计提、利息计提。通用「记」字，**每月按日期从 1 连续编号**（同一天按 资金→进货→销售→手工→月末 的顺序）。 |
| 一本账多长 | **一年一本**（月份网格 24 个月，从建账月起，留余量）；第二年新开一本，期初＝上一本年末数 |

## 4. 基础

### 4.1 基础资料
① 参数：公司名称、建账日期、纳税人类型（一般纳税人/小规模）、销项税率 13%、小规模征收率 1%、运费税点 7%、销货运费记入（主营业务成本/销售费用）、
  投产月份（建厂费用开始摊）、建厂费用摊销月数 36、多少天没回款提醒 60、对账工作日 5、付款天数 30、会计主管/记账/出纳/审核/制单（凭证签字栏）、凭证号是否打印。

## 8. 月末引擎要点

- **原料**（_料，原料 k × 月 m，24 个月）：入量＝进货登记（有效、已定价）数量；入额＝货款不含税＋运费不含税（运费按进货行的物料）＋回收料产出额（产量×定额）；
  投料量＝生产日报各槽（槽的原料号＝k）的吨数；单价＝IF(月初量＋入量>0,ROUND((月初额＋入额)/(月初量＋入量),6),上月单价)；
  出库额：投料额＋销售（卖原料/废料）额；按「出完兜底」：出量≥可用量时出额＝月初额＋入额。投料额再按产品分（各产品投料量×单价，最后一个产品兜底）。
- **产品**（_品，产品 p × 月 m）：完工量＝产量吨；完工额＝_本 完工成本；单价、销售成本同上兜底。
- **_本**：直接材料 DM(p,m)＝Σ_k 投料额(k,p,m)；制造费用池 OH(m)＝4101 本月发生（**按来源求和**：_资/_进/_手 记到 4101 的＋折旧（生产）＋建厂摊销（制造）＋工资计提（生产、车间管理）−扣社保冲回）＋上月留；
  权重 W(p,m)＝产量吨×分摊系数；ΣW>0 时分配（累计舍入，合计正好）否则整月留；完工成本＝月初在产＋DM＋分到的 OH − 废料扣（废料吨×定额）；产量 0 的产品 DM 留在在产。
- **折旧**（_卡）：卡片×月网格，取得次月起提、提满为止、建账前不提、处置月以后不提，最后一个月补尾差；按部门汇总。
- **建厂摊销**（_摊）：_资 每行（科目 1801 的付款）带「开始月序、月数、月摊额、末月额」；⑧ 期初 1801 按参数月数从建账月摊；按「计入」（制造/管理）分两行。
- **利息**（_息）：出借人 L × 月 m：本月利息＝ROUND(d×(本金_{<月初}×天数 + Σ本月事件(金额×(下月初−日期))),2)，d＝年利率/基数；事件＝资金台帐借款类行（往来＝L）＋垫付账户行（垫付人＝L）＋⑦ 建账前明细；借款和投资分开算。
  截至截止日累计应计＝d×(Σ金额×截止日 − Σ金额×日期)（只算日期<截止的事件）；借款利息视图逐笔列：天数＝截止−日期，本笔利息＝±金额×d×天数。
- **工资**：_工 按月×部门汇总应发、扣社保、其他扣款。
