# A072 · 化工（十水焦磷酸钠）生产销售财务模板

> **你说的：** 需要设置一套化工行业生产销售十水焦磷酸钠的财务模板，可以参考这套机械零部件加工行业帐套模块内容，并增加以下：
> 现金流量表、资产负债表、记帐凭证、借款明细表体现利息、进销存、固定资产、工人工资、成本费用分析：比如中1吨成品的成本是多少：
> 原材料、固定资产折旧分摊、建厂的费用分摊等。投资款、借款、员工报销没有发票的由老板个人垫付款，需要有跟进垫付款的发票表参考提供表格。
> 由于是合伙的都需要收取利息，需要增加一个有借款、打款利息计算的表格（有从银行借的，有从个人借的，还有我们老板垫付的现金部分也属于借款）。
> 提供的截图是费用登记、购进即物流登记表那个、销售、生产相关的表格。目前是生产一个成品十水焦纳，后面要可以继续增加产品，
> 原材料领用到成品入库都有登记表格。进销货时我们的运费是单独计算的要记在成本中。这是我这边记流水账时统计的项目。
> 生产时除了水电还有供热费。还有员工报销的里面买的材料、加油、日常用品等我这边还要细分一下，按报销人员和报销项目统计。

## 一句话

**一本表 `A072_化工十水焦磷酸钠财务模板.xlsx`，一本管一年。平时只录蓝色的几张表，跟你截图里那样记流水就行；凭证、三大报表、每吨成本、借款利息、垫付补票跟进都会自动算出来。登记表哪里都可以插行、删行、排序。**

机械那本里的【付款审批】【采购计划】这一套你删掉了，这本也没有放。资金台帐、日报月报、费用统计、往来、对账单、发票跟进、首页、数据校验都保留了，并且按化工生产改过。

## 启用三步

1. **删示例。** 各表里灰底、备注写着「示例」的行，整行删掉。
   - 包括基础资料 ⑤ 人员、⑦、⑧，以及往来单位、固定资产、固定支出里的示例行。
   - 收支类别、报销项目、会计科目是预置好的，按自己的情况改名、增删就行。
   - 【基础资料】② 账户里，农行公户期初 200,000、现金期初 3,000 是**示例数**，一定要改成你们自己的余额。
2. **填期初**，填建账日前一天晚上的数。
   - 【基础资料】填：
     - 公司名称；
     - 建账日（必须是某月 1 号）；
     - ② 各账户的期初余额（按网银、现金实点核对）；
     - ⑦ 建账前的借款、合伙人投资、老板垫付，一笔一行，带打款日期，利息靠它算；
     - ⑧ 其他期初，比如押金、还没摊完的建厂费用（填剩余月数）、欠的工资和税费。
   - 【往来单位】填客户的期初应收、供应商的期初应付；出借人（银行、个人、合伙人、老板）填利率和到期日。
   - 【物料档案】填期初盘点的数量和单价。截图里 7/31 盘点的成品 563 袋、废料 103 袋已经填好了；成品单价 2600 是示例，请按实际改。
   - 【固定资产】一台设备一张卡片。
   - 填完看【数据校验】，「期初试算平衡」要是 √。
3. **每天录。** 从建账日起每天录蓝色的表；月底登【工资表】和【月末盘点】。每天看一眼首页，有 ✗ 就去【数据校验】，点名字跳到出错的那一行。

| 表 | 一行是什么 | 要点 |
|---|---|---|
| **资金台帐** | 一笔钱 | 照你发的收支项目截图记流水。银行、现金、微信，还有「老板垫付」「备用金」这种账户都在这一张，收入、支出只填一个。<br>员工报销选「员工报销」，再填**报销人**和**报销项目**（材料配件、加油、日常用品……）。<br>电费、水费、供热费这种先用后付的，「所属月份」填用的那个月。<br>老板个人掏钱付的，账户选「老板垫付」，类别选买了什么，编号按第 3 行提示的下一个编号填（202608-X01…）。<br>右边自动出本账户即时余额、记到哪个科目、这一行的问题 |
| **进货物流登记** | 一车 | 照你发的进货物流截图：车牌、司机、装货点、物料、供应商、数量、单价。<br>**运费单独一栏**（每吨运费或整车运费，加税点），自动算进这车原料的成本。<br>还没定价的单价空着：先按物料档案的参考单价暂估，定了价回原行补 |
| **销售台账** | 一车 | 照你发的销售截图：合同号、客户、单价、吨位、提货日期、车牌、签收对账、发票号。<br>**我们出运费的**，填物流单位和运费，自动记进成本（主营业务成本-销货运费） |
| **生产日报** | 一天一个产品 | 照你发的生产截图：产量（袋）、废料（二次过滤）、每种原料投了多少吨。<br>原料列的名字跟着物料档案「生产日报第几列」变。<br>以后加产品：在物料档案 ② 产品里加一行，生产日报的「产品」选它就行 |
| **工资表** | 一个人一个月 | 部门（生产 / 车间管理 / 管理 / 销售）决定工资进生产成本还是期间费用；扣社保、扣借支、其他扣款也在这里填 |
| **发票登记** | 一张票 | 主要登**收到**的票。老板垫付、报销先「待补票」的，补到票时在这里登，并填**垫付编号**，补票跟进里就消掉了。开出的票在销售台账填发票号就行 |
| **月末盘点** | 一种料或产品 | 月底填实盘数量，差多少自动出盘点凭证 |

|---|---|
| 客户打来货款、收到承兑 | 【资金台帐】账户选收到钱的账户（承兑选「承兑汇票」账户），类别「收客户货款」，往来单位选客户，填收入；退给客户的记支出 |
| 承兑到期、贴现 | 记两行，类别都选「承兑到期/贴现入账」：承兑汇票账户记支出（票面），银行记收入（实际到账）；贴现少的钱在承兑汇票账户记一行「贴现息」 |
| 进一车原料 | 【进货物流登记】一行。退货：数量填负数。扣款折让：数量空着，货款金额填负数 |
| 付原料货款、付运费 | 【资金台帐】类别「原材料材料款」，付运费选「原材料运输费」或「销货运费」；往来单位选供应商或物流单位，自动冲进货、销售里欠下的 |
| 发一车货 | 【销售台账】一行。还没定价的单价空着，出库成本照算，收入定价后再进。卖废料、卖原料：「产品」选那种料 |
| 老板自己掏钱付的 | 【资金台帐】账户选「老板垫付」，类别选真实用途（伙食费、员工报销……），票种空着＝待补票。<br>公司还老板：只在银行记一行，类别「垫付现金已报」，往来单位选老板 |
| 补到发票 | 【发票登记】一行，方向「收到」，「垫付编号」填那一笔的编号：专票自动抵进项，「待补票」也就消掉了 |
| 员工报销、备用金 | 员工报销：类别「员工报销」，报销人、报销项目必填。<br>备用金：在基础资料 ② 建一个「备用金」类型的账户（人员填拿钱的人）。<br>- 发备用金：银行记支出，类别「发备用金」，往来单位选这个人；<br>- 他用备用金买东西：在他的备用金账户记支出；<br>- 退回来：银行记收入，类别同样选「发备用金」 |
| 借款、还款、付利息 | 出借人先在【往来单位】建好（类型选「出借人」，填出借人类别、利率、到期日）。<br>借进来选「借款到账」，还本金选「还出」，往来单位选出借人；付利息选「农行利息」「微众贷款利息」这一类。利息每月自动计提 |
| 合伙人投资 | 类别「投资款」「退还投资款」。按投资年利率算的「利息」每月自动计进利润分配，付的时候选「付投资款利息」 |
| 工资 | 月底【工资表】一人一行，自动计提。发工资时【资金台帐】类别「员工工费」，预支工资选「员工借支」 |
| 电费、水费、供热（下个月才付） | 付款那一行「所属月份」填用电、用汽的那个月（填 8 就行），成本就算进那个月 |
| 一次付几个月房租、建厂费用 | 环评、认证、装修、开办费这些类别已经设好，会自动按月摊。一次付一年房租的：在 ③ 收支类别新建一个类别（如「厂房租金（年付）」），分摊月数填 12 |
| 买设备 | 类别「机械设备费」，再到【固定资产】登一张卡片（原值填不含税），每月自动折旧，按部门进生产成本或管理费用 |
| 设备卖掉、报废 | 卡片填处置日期（之后不再提折旧），清理的账请会计在【手工凭证】做；不做的话，数据校验会提示卡片原值和账上对不上 |
| 自己账户之间倒钱 | 记两行「内部转账」：转出账户记支出、转进账户记收入，金额一样 |
| 缴税 | 选「缴税-增值税」「缴税-附加税印花税」「缴税-所得税」「缴税-代扣个税」，一张缴款书有几种税就拆几行 |
| 加一个新产品 | 【物料档案】② 产品加一行：名称、每袋几吨、分摊系数（制造费用按「产量×系数」分）、废料归入哪种回收料。生产日报、销售台账的「产品」就能选它了 |
| 加一种原料 | 【物料档案】① 原料加一行。要在生产日报里录投料，就给它填「生产日报第几列」（1～12 列） |

## 每吨成本怎么算（成本费用分析）

一吨成品的成本 ＝ 原材料 ＋ 分到的制造费用 － 废料回收，每个月算一次：

- **原材料**：每种原料月底算一次**加权平均单价**＝（月初结存金额＋本月进货金额，**进货运费也算在里面**）÷（月初数量＋本月进货数量）。投料吨数（生产日报）× 这个单价＝直接材料。成本费用分析里每种原料单列，「其中进货运费」也单列出来。
- **制造费用**：会计科目「生产成本-制造费用」下面每一个明细各自汇总，比如水费、电费、**供热费**、车间工资和社保、**设备折旧**（生产部门的固定资产卡片）、**建厂费用摊销**、厂房租金、维修、吨袋活性炭这类辅料包装。
  - 每一项都按当月各产品的「产量吨 × 分摊系数」分给产品（只有一个产品时就全给它）。
  - 当月一吨都没生产，这些费用留到下个月再分。
- **废料（二次过滤）**：按物料档案里的「定额单价」冲减成本，默认 0（不冲）。
- 生产日报只录了投料、产量是 0 的，材料先挂在「在产品」，下个月有产量时一起转。

成本费用分析选一个产品，出 1～12 月：
- 产量、各原料单耗、收率；
- 每吨的各原料、各制造费用明细、完工成本（跟凭证核对，差 0）；
- 按销量算的每吨销售成本、每吨销货运费、每吨期间费用、每吨完全成本、不含税均价、每吨毛利、每吨经营利润。

本年那一列是全年金额合计 ÷ 全年产量，不是各月平均。

## 借款、投资、垫付的利息怎么算（借款明细及利息）

- **谁借的**：出借人在【往来单位】建，类型选「出借人」，出借人类别选银行、个人或合伙人，再填：
  - 借款年利率；
  - 投资年利率（合伙人投资要收「利息」的填这个）；
  - 计息天数（一年按 365 还是 360 天算）；
  - 到期日。
- **本金从哪来**：
  - 建账前的：【基础资料】⑦，一笔一行，带打款日期。
  - 建账后借进、还出：【资金台帐】「借款到账」「还出」。
  - 投资、退投资：「投资款」「退还投资款」。
  - **老板垫付的现金也算借款**：「老板垫付」账户里每一笔支出，都是老板借给公司的钱；公司用「垫付现金已报」还给老板，就是还本金。
- **怎么算**：按天单利，算头不算尾，每月末自动计提，只算到截止月。
  - 借款和老板垫付：计入财务费用-利息支出，挂应付利息。
  - 合伙人投资：按投资年利率计入「利润分配-应付利润」。它不算费用，利润表下面单独列「减：投资款利息」和「分完投资利息后的利润」。
  - 付利息时冲掉这些挂账。
- **银行借款不填利率的**：银行每月扣多少就记多少（直接进财务费用），不计提。
- 【借款明细及利息】上半看每个人的本金、利息、到期日；下半选一个人，看每一笔打款、还款各算了多少天、多少利息。

## 第二年

1. 把这本另存一份当新的一年（或者用空模板），在【基础资料】建账日改成次年 1 月 1 日。
2. 旧本【年末结转】里已经按新本的列顺序排好了年末数：账户余额、往来单位期末应收应付和未开票欠票、物料期末数量单价、固定资产（累计折旧）、⑦ 每个出借人的本金、⑧ 没摊完的建厂费用和预付房租（带剩余月数和摊到哪个科目）。
3. 一块一块复制，到新本对应位置「选择性粘贴 → 数值」。
4. 新本里删掉旧的流水，看【数据校验】期初试算平衡 √。

## 注意

- 用 Excel 2010 以上或 WPS 打开。所有公式都是这两个软件都认的；没有用宏，也没有用「今天」这种会自己变的函数。
- **容量**（一年够用；超了【数据校验】会提示，再开一本）：

  | 表 | 最多 |
  |---|---|
  | 资金台帐 | 3000 笔 |
  | 进货物流登记 | 800 车 |
  | 销售台账 | 800 车 |
  | 生产日报 | 600 行 |
  | 工资表 | 800 行 |
  | 发票登记 | 1200 张 |
  | 月末盘点 | 300 行 |
  | 手工凭证 | 300 行 |
  | 往来单位 | 300 家 |
  | 原料 | 40 种 |
  | 产品 | 10 种 |
- 公式比较多，改一格要算一两秒。一次录很多时，可以先把计算改成「手动」（公式 → 计算选项），录完按 F9。
- 客户、供应商、物料、账户、收支类别都从下拉选；新的先到【往来单位】【物料档案】【基础资料】加一行（全称、别名也认）。不要改表名，否则链接会失效。
- 绿、紫、橙色的表和首页是自动的，有保护（没有密码），只有黄格子能改。
- 首页的截止日期平时空着（＝最后一笔的日期）。想看以前某一天的，就在黄格填日期，看完清空。
- 固定资产、建厂费用（1801）补到专票时，只消掉「待补票」，进项税不自动抵；要抵的话请会计在手工凭证做。

## 要跟你确认的

下面这些我先按常见做法设好了，跟你们实际不一样的告诉我，我来改：

1. 公司是**有限公司**还是**合伙企业**？合伙人的钱算「投资款」（按投资年利率分利息、不进费用）还是「借款」（利息进财务费用）？现在两种都能记。
2. 截图里「**垫付现金已报 / 未报**」原来是什么意思？现在的做法：「已报」＝公司把钱还给老板（只在银行记一行）；「未报」不用选，没还的就是没报。
3. 是**一般纳税人**吗？销售单价、进货单价是**含税价**吗？现在都按「是」设的。
4. 几个类别具体指什么：「原料业务费」「原材料材料款2」「员工工费」和「劳务工资」的区别、「材料费」「管理费」。现在分别记在：
   - 原料业务费：制造费用-其他；
   - 原材料材料款2：付货款（跟「原材料材料款」一样冲供应商欠款）；
   - 员工工费：发工资；
   - 劳务工资：制造费用-劳务费；
   - 材料费：制造费用-机物料消耗；
   - 管理费：管理费用-物业管理费。
5. **废料（二次过滤）**最后去哪了（卖掉、回炉、扔掉）？要不要按一个定额单价冲成本？现在定额单价是 0。
6. **投产月份**（建厂费用从哪个月开始摊）、建厂费用一共多少、按几年摊？现在默认 2026 年 7 月、36 个月。厂房租期多长？
7. 7/31 盘点的成品 563 袋、废料 103 袋，每袋按多少钱估？建账日从 2026-08-01 开始对不对？
8. 运费的 **7% 税点**开的是什么票？哪些销售是我们出运费？
9. **微众、农行的借款**：本金、年利率、到期日、利息怎么扣？
10. **吨袋**是买来就算成本，还是按用了多少袋算？现在是买来就算。
11. **宿舍租金、伙食费**算生产成本还是管理费用？现在算生产成本（职工福利）。
