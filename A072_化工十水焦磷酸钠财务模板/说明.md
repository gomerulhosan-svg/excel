# A072 · 化工（十水焦磷酸钠）生产销售财务模板

> **你说的：** 需要设置一套化工行业生产销售十水焦磷酸钠的财务模板，可以参考这套机械零部件加工行业帐套模块内容，并增加以下：
> 现金流量表、资产负债表、记帐凭证、借款明细表体现利息、进销存、固定资产、工人工资、成本费用分析：比如中1吨成品的成本是多少：
> 原材料、固定资产折旧分摊、建厂的费用分摊等。投资款、借款、员工报销没有发票的由老板个人垫付款，需要有跟进垫付款的发票表参考提供表格。
> 由于是合伙的都需要收取利息，需要增加一个有借款、打款利息计算的表格（有从银行借的，有从个人借的，还有我们老板垫付的现金部分也属于借款）。
> 提供的截图是费用登记、购进即物流登记表那个、销售、生产相关的表格。目前是生产一个成品十水焦纳，后面要可以继续增加产品，
> 原材料领用到成品入库都有登记表格。进销货时我们的运费是单独计算的要记在成本中。这是我这边记流水账时统计的项目。
> 生产时除了水电还有供热费。还有员工报销的里面买的材料、加油、日常用品等我这边还要细分一下，按报销人员和报销项目统计。

## 平时录的（蓝）

| 表 | 一行是什么 | 要点 |
|---|---|---|
| **资金台帐** | 一笔钱 | 照你 41 号截图的收支项目记流水：银行、现金、微信，还有「老板垫付」「备用金」这种账户都在这一张。收入、支出只填一个。员工报销选「员工报销」，再填**报销人**和**报销项目**（材料配件、加油、日常用品……）。电费、水费、供热费这种先用后付的，「所属月份」填用的那个月。老板个人掏钱付的，账户选「老板垫付」，类别选买了什么，编号自动排（202608-X01…）。右边自动出本账户即时余额、记到哪个科目、这一行的问题 |
| **进货物流登记** | 一车 | 照 40 号截图：车牌、司机、装货点…物料、供应商、数量、单价；**运费单独一栏**（每吨运费或整车运费、税点），自动算进原料成本。还没定价的单价空着，先按物料档案的参考单价暂估，定了价回原行补 |
| **销售台账** | 一车 | 照 42 号截图：合同号、客户、单价、吨位、提货日期、车牌、签收对账、发票号；**我们出运费的**填物流单位和运费，自动记进成本（主营业务成本-销货运费） |
| **生产日报** | 一天一个产品 | 照 38 号截图：产量（袋）、废料（二次过滤）、每种原料投多少吨；原料列的名字跟着物料档案「生产日报第几列」变。以后加产品，在物料档案加一行，生产日报「产品」选它 |
| **工资表** | 一个人一个月 | 部门（生产 / 车间管理 / 管理 / 销售）决定工资进生产成本还是管理费用；扣社保、扣借支、其他扣款 |
| **发票登记** | 一张票 | 主要登**收到**的票。老板垫付、报销先「待补票」的，补到票时在这里登，并填**垫付编号**，补票跟进里就消掉了；开出的票在销售台账填发票号就行 |
| **月末盘点** | 一种料或产品 | 月底实盘数量，差多少自动出盘点凭证 |

## 自动的

| 表 | 是什么 |
|---|---|
| **首页** | 钱（可用资金、承兑、今天和本月收支、各账户余额）、欠（客户欠、欠供应商、欠物流、欠老板垫付、欠合伙人和个人借款、银行借款，带应计利息）、本月预计交多少增值税、产销存（本月产量销量、成品库存、主原料库存够用几天）、每吨成本和利润、提醒、导航 |
| **资金日报 / 资金月报** | 选一天 / 一个月：每个账户的收支余额；按收支类别汇总 |
| **费用统计** | 按你自己的收支类别（41 号截图的名字和顺序）× 1～12 月；员工报销展开到报销项目；工资计提、折旧、建厂费用摊销、利息这些不走钱的也列出来 |
| **报销统计** | 报销人 × 报销项目，选起止月；每人按月；其中老板垫付的、备用金的 |
| **个人垫付现金明细** | 照 39 号截图：选垫付账户和月份，出这个月的垫付明细（序号、日期、编号、摘要、往来单位、金额、票种、已报/未报、备注、合计、制表审核）；右边**补票跟进**：还没补到票的按天数排，「无票」单列（汇算清缴要调增） |
| **借款明细及利息** | 上半：每个出借人（银行、个人、合伙人、老板）的借款本金、投资本金、利率、本月利息、本年利息、已计提没付、到截止日应计、到期日；下半：选一个人，看每一笔打款、还款、计息天数、本笔利息 |
| **进销存** | 选月份：原料、回收料（废料）、产品，月初、入库（其中运费）、出库、盘点差、月末的数量和金额 |
| **成本费用分析** | 选产品：1～12 月 **每吨成本拆开看**——各原料（其中进货运费）、水费、电费、供热费、车间工资、**设备折旧分摊**、**建厂费用摊销**……减废料＝完工成本；再按销量算每吨销售成本、销货运费、期间费用、完全成本、毛利 |
| **利润表 / 资产负债表 / 现金流量表** | 小企业会计准则格式；利润表 1～12 月＋本年，下面加产量、销量、均价、每吨成本、毛利率、投资款利息、分完利息后的利润；资产负债表选月份，平不平自己核对；现金流量表跟货币资金核对 |
| **客户往来 / 供应商往来 / 对账单 / 发票跟进** | 跟机械那本一样用；供应商往来含物流单位（运费）；对账单选单位和日期，物流单位按车列运费 |
| **数据校验** | 哪张表哪一行有 ✗、账平不平、库存有没有负数、工资表漏没漏登……点名字跳过去改 |

**会计用的**（首页不放）：凭证汇总、记账凭证（A4 一页两张，选月份和从第几页起打印）、科目余额表、手工凭证（调账用）、年末结转（第二年复制期初用）。
