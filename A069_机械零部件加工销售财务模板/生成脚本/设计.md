# A069 机械零部件加工销售财务模板 · 设计（定稿；内部开发时叫 A072）

## 用户要的（原话要点）

1. 往来款跟进，直接出对账单；跟进发票，发票手工登记（不用税局导出的）。
2. 资金台帐 7 个账户，**混合录入**，有**即时余额**；能筛选客户、供应商、费用。
3. 资金日报表、月报表；费用按月统计。
4. 付款审批表：老板审核哪些要付、哪些不付。
5. 每月固定支出、每月计划支出；每天采购计划的提交；汇总表格。
6. 业务：接订单回来加工（自产），也买产成品回来销售（外购成品）。快工单导出的入库单没有金额，以后**手工录采购单、销售单**。
7. 生产这块不知道怎么处理，没法盘点进销存；以前只有资金台帐和往来款，没出过利润表。要全套重新设置，**尽量简单、能马上启用**。

已有资料（`参考/`）：10 月 7 个账户余额、36 家客户应收、10 家供应商应付、供应商往来日记账、西安明聚合同台账、快工单采购单和销售出库单导出、手写日记帐照片。

## 口径

**截止日期**（首页黄格；空＝资金台帐、销售、采购三张表里最晚的实际日期，挡掉建账日＋800 天以后的；最晚那天往前 31 天里只有 ≤2 笔、而且更早还有数 → 当成年份打错，截止用再往前一个月的最后日期，首页和数据校验提醒）。报表一律只算日期 ≤ 截止的行。

**建账**：建账日（默认 2026-10-01）＝期初是前一天晚上的数。资金台帐、销售、采购、发票里日期早于建账日的行 ✗ 不算（已经在期初里）；建账前发货、现在才定价的，日期改成建账日、备注写原日期。

**资金**
- 8 个账户混录；内部转账**只用两行记法**（转出账户记支出、转进账户记收入，类别都选内部转账；手续费另记一行）。
- 即时余额按**表里上下顺序**（跟手写帐一样）：本账户期初＋前面各块（每块 50 行）＋本块到本行的净额；日期比上面同一账户早的行 ⚠（按日期排一下序就对了）。报表里的余额一律**按日期**算。
- 承兑汇票是一个「票据」类型的账户：收票＝收客户货款记进承兑账户；背书＝付供应商货款从承兑账户出；贴现/到期＝两行内部转账（票面），贴息另记「承兑贴息」（财务费用）。可用资金不含票据。
- 收支类别只配一个「算到哪」（归类，12 个）：收客户货款、付供应商货款（冲往来，要选往来单位）；生产成本、销售费用、管理费用、财务费用、税金、其他支出（进利润表）；其他收入；内部转账；不算收支（借款、还款、老板存取、保证金、还信用卡）；买设备（不进当月费用，折旧另估）。
- 「所属月份」（选填）：工资、电费是上个月的就填几月，利润表、费用统计按所属月份算；资金日报月报、固定支出已付按付款月份。

**往来**
- 往来单位名字一律先规范成简称（简称、全称、其他叫法都认，去空格、半角括号改全角）。
- 客户欠款＝期初应收＋发货（销售登记金额）－回款（收客户货款：收入－支出）；欠供应商＝期初应付＋到货－付款（付供应商货款：支出－收入）。负数＝预收/预付。
- 待定价：有数量、单价金额都空 → 金额按 0、⚠，往来和首页提示几笔；定价后回原行补。
- 退货、折让、质量扣款记负数行。供应商只当客户用的单位选「客户和供应商」。
- 零星现买、不用对账的不建档，资金台帐记「零星料钱（现买）」；建了档的供应商付款要选付供应商货款（选了费用类别 ⚠：成本会算两遍）。

**发票**
- 开出/收到空着按单位类型；两头往来的单位必须填。税率空＝13%，填 13 或 0.13 或「13%」都认，「免税」＝0。税额空＝价税/(1+税率)×税率。
- 应开票＝期初未开票＋要开票的发货（行上「开票」空＝按单位设置）；未开票＝应开票－已开出。欠票（供应商）同理。单位设成「不要」开票的（个人供应商）不算。
- 只登本公司真实开出、收到的发票。

**付款审批（含每月计划支出）**
- 状态：没填结果＝待审批；同意/部分同意：已付 0＝待付款，没付够＝部分已付，付够＝已付；不同意；暂缓。批准金额空＝申请金额。
- 已付＝资金台帐里「关联单号」＝本单的支出－收入（≤截止）。关联单号下拉只列待付款的单（单号＋收款单位），镜像取空格前的部分。
- 检查：单号重复/没填 ✗；部分同意没填批准金额 ✗；不同意/暂缓却付了、没审批就付了、付超了、申请以后这家有付款没填单号、已经预付 ⚠。

**固定支出**
- 已付（按付款月份）＝关联单号填了这个编号的支出＋（这条是同一「类别|收款单位」里的第一条时）没填单号、类别（填了收款单位的再对单位）对得上的支出。带审批单号的付款不算固定支出（不会和付款审批重复扣）。

**利润表（简单管理口径，金额按实际成交价，带票的是含税价，跟对账一致）**
- 销售收入＝发货（按发货月），分自产加工、外购成品。
- 销售成本＝采购（6 类，按到货月）＋资金台帐「生产成本」（按所属月份）＋设备折旧（估，建账月起每月）＋库存变动（本月估了值、前面也估过（含建账日估值）：上次估值－本次估值；没估＝0，标「没估」）。
- 期间费用、税金、其他收入、其他支出按所属月份。利润＝毛利－期间费用－税金＋其他收入－其他支出。
- **生产怎么处理**：财务不跟生产过程；料、外协、外购成品买进来就进成本，工资电费刀具算生产成本；月底大概估一下仓库里料和货值多少（可不填），差额调成本。

## 容量

资金台帐 3000 笔（每块 50 行，60 块）、销售/采购各 1500 行、发票/付款审批/采购计划各 800 行、往来单位 300 家、账户 15、收支类别 80、人员 50、固定支出 50、库存估值 36 个月、快工单粘贴区 1000 行。约够一年半到两年；用满了另起一本（期初＝上一本最后的余额和欠款）。

（第一版按 6000 / 3000 / 2000 做，整本 70 万个公式，LibreOffice 里改一格要重算约 11 秒；减半以后约 3.5 秒，日常够用。）

## 做法

- 录入表只放录入列＋右边只给人看的显示列（ROW()-ROW(表头) 取隐藏表第 n 条）；逐行计算放隐藏表，按「第 n 条」取数：`INDEX(录入表!$X$表头行:$X$1048576, n+1)`。
- 查看表只用定义名称做 SUMIFS/COUNTIFS，合计带有效条件；名字、单号做条件过 esc()，单号用 "#"&规范号；空键不做条件。
- 只用 Excel 2010 / WPS 都有的函数：不用数组公式、INDIRECT、TODAY；OFFSET 只在下拉来源里用（下拉来源不写开头的 =）；SUMPRODUCT 只做区域相乘。
- 「最后日期」类用键：单位号×100000＋日期，LARGE/COUNTIF 取；即时余额、日期乱用 50 行一块的块表；长链不超过 60 层。
- 测试：`A072_SMALL=1` 小容量（资金 600、销售采购 300、其余 200、快工单粘贴区 200）给开发用；成品一律全容量。

  采购登记「入库单号」照抄 CGRK…，销售登记「出库单号」照抄 HTCK…；新加【快工单核对】：月底把采购入库单 / 销售出库单连表头粘到 J5，
  按第 5 行表头名找列（单号、日期、数量、商品名称、客户），左边逐张显示在登记表里登了几行（COUNTIF 单号键带通配）、销售出库单再比数量；
  成品入库单只提示「财务不用登」。预置 10 月 1～9 日 7 张采购入库单（真实数据，不是示例）。
- **生产不加成品入库表、不做成品进出存**：数量看快工单；月底问仓库三个数（圆钢吨数×每吨价、主要成品套数×每套成本、外协厂的料）填⑤。
- **钢磊往来账里的情况都不用改结构**：按吨计价（数量填吨）；「科泓开票」按票面 10% 加点＝采购登记一行（数量＝票面、单价 0.10、类别其他、要票否）；
  替供应商付给第三方＝资金台帐往来单位填这家供应商、摘要写实际收款人（审批单收款单位也填这家供应商）；供应商退回＝付供应商货款记收入栏，对账单显示负数付款；
  用别人的卡付＝加一个「别人代付」账户记两行（借款/老板存取 进、付供应商货款 出）。
- 河北钢磊 9/30 余额待用户核对（日记账 817,472.88 / 往来账推算 817,472.28）。
- 文字类：日期是文字时提示用分列；单位找不到时提示代付的记法；有效性提示 ≤255 字（make 里 assert）；数量列改 General（不显示多余的小数点）。
- 最终复核后统一口径（共享层改，所有查看表跟着走）：
  - 「待定价」只数日期 ≤ 截止的发货 / 到货；「最后发货 / 到货」只认金额 ≥ 0 的行（退货不算）。
  - 固定支出「本月已付」只算 ≤ 截止的付款，同月同一项多笔时只认第一笔先占（本月先占），不会一笔付款同时抵两项。
  - 首页「本年利润」和「库存变动」跟利润表同一套算法（本年＝1 月到截止月；库存变动用上月末估值，建账第一个月用建账日的期初库存）。
  - 账户名重复时首页余额只算一次；资金台帐所属月份比日期早 6 个月以上 ⚠ 提示、早于建账月 ℹ 提示。

  - 有效性提示里不用表情符号（★ 代替 💡），各表打印区域只到最后一行有数的地方。
