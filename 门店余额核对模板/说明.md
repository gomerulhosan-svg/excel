## 怎么用

**什么都不用填**，【数据录入】照原来录，【门店余额核对】自己出数。只有黄格子可以动：

- **B4 截止日期**：空着＝全部（到最后一笔）；填某一天＝算到那天为止。没写日期的记录按「收支所属月份」的月底算。
- **④ B 列「不算门店的名字」**：默认 公司、配送、预收、收款、其他收款、股东借款、内部转款、房租及其他、12月门店。
  以后有新的「不是门店」的名字（比如新开一个总部账），往下空格里填上就行。
- **① H12 公司年初结余**：一般空着（自动算）。
- **⑥ G 列 银行对账单余额**：想跟银行实际余额对，就把截止日期那天银行 App / 对账单上的余额填进去（现金填盘点数）。

## 表里有什么

| 块 | 内容 |
|---|---|
| ① 核对 | 门店余额、收款、付款、公司年初结余 → **应存**；14 个账户余额 → **实存**；**差额＝实存－应存**（✓／✗ 自动提示） |
| ② 按月看 | 1～12 月每个月底的同一套数，看差额是哪个月冒出来的 |
| ③ 差额从哪来 | 没走银行账户的记录分四类列出来（调拨、平台款分摊等、货款直抵费用、写错账户名的），净额应该都是 0 |
| ④ 收款 / 付款明细 | 公司、配送、内部转款、股东借款、12月门店、没填门店的…… 各收付多少、其中走银行的多少 |
| ⑤ 门店余额明细 | 每个门店：年初余额、首月手加的数、收入、支出、期末余额；还标出【门店月度收支统计】少算的 |
| ⑥ 账户余额 | 14 个账户的年初、收入、支出、账上余额；可填对账单余额对差 |

## 口径（为什么这样算）

- **门店余额**＝每个门店在【门店月度收支统计】里的年初数（G 列）＋那张表首月公式后面手加的数 ＋ 这个门店在【数据录入】的收入 － 支出。
  门店名单就用【门店月度收支统计】里的（含自助药机、疼痛馆、已关的 8 家店），跟你领导平时看的门店余额是一个数。
- **收款 / 付款**＝【数据录入】里不算门店的那些行（I 列是公司、配送、内部转款、股东借款……或者空着）。
  调拨、货款直抵费用这类不走银行的记录也算在里面 —— 它们是在门店和公司之间挪，一边门店少了、另一边配送多了，合起来正好相抵。
- **公司年初结余**＝年初银行余额 － 年初门店余额合计。年初那天银行里的钱扣掉属于门店的，剩下的就是公司的
  （现在是 −11,416,683.47：公司以前用门店的钱进了货）。旧表从开账算起，收款付款里本来就含这部分；这本表从 2026-01-01 开始，所以单列一行。
- **实存**＝数据录入第 5～18 行 14 个账户的期初 ＋ 这些账户的收入 － 支出（跟各账户子表的「当前余额」是一个算法）。
- 这样算，**只要每一笔都记在银行账户上、或者不走银行的那些一收一付配平，差额就一定是 0**；差额不是 0，③ 会告诉你是哪一类记录没配平。

## 现在的结果（9.27 那本的数据，算到最后一笔 2026-09-25）

| 项目 | 金额 |
|---|---:|
| 门店余额 | 14,370,265.95 |
| 加：收款 | 45,857,617.97 |
| 减：付款 | 44,762,992.40 |
| 加：公司年初结余 | −11,416,683.47 |
| **应存** | **4,048,208.05** |
| **实存**（14 个账户合计） | **3,917,171.05** |
| **差额** | **−131,037.00** |

差额从哪来（③）：

- 调拨 179 笔：收 24,327,572.53、付 24,327,572.53，**配平了**。
- **没记账户的其他记录 183 笔：收 2,504,140.68、付 2,372,733.88，多了 131,406.80** —— 主要是平台款（上海汇付聚合款等）先记总数再按门店拆、
  报销拆分这类，拆出来的合计跟总数对不上。去【数据录入】按「公司账户」筛选空白、再按日期看。
- 货款直抵费用 1,225 笔：收 209,467.20、付 209,837.00，差 −369.80。
- ② 按月看：1 月就差 5,890（2026-01-12 一笔没记账户的「付春节公关费」5,890），之后每月都有变化，8 月底到 −131,037.00。

另外查出来、建议核对的几处（都不影响你原来的表，只是新表里看得出来）：

1. **【门店月度收支统计】少算了 92,782.93**：有些门店的记录「收支所属月份」没填（或填的不是 2026 年），那张表按月份取数取不到。⑤ 的 H 列逐店列出来了（新隆分店少 34,783.31 等）。
2. **疼痛馆的首月手加数 205,006.84 跟自助药机一模一样**：【门店月度收支统计】第 665 行（疼痛馆）公式后面也加了「+205006.84」，像是从自助药机那行复制过来的，疼痛馆余额因此多了 20 多万。
3. **年初就对不上 4,673,771.15**：【门店月度收支统计】里配送＋公司的年初是 −6,742,912.32，按银行倒推应该是 −11,416,683.47。
   这是从旧表带过来的年初数没对平，不影响上面的差额（① 用的是倒推的数）；如果领导要用旧表的数，在 ① H12 手填，差额会多出这一块。
